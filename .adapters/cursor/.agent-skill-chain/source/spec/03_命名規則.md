# 命名規則

命名は **意図が分かること** を最優先とする。

---

## UseCase

動詞から始める。

例

- create_user
- upload_audio
- retry_job

---

## Query

取得操作。

例

- get_user
- list_jobs
- get_dashboard

---

## Event

過去形で表す。

例

- UserCreated
- OrderPlaced
- AudioUploaded

---

## Module

業務ドメイン名。

例

- auth
- orders
- jobs

---

## 禁止命名

以下の曖昧な名前は禁止する。

- helpers
- misc
- common
- utils

理由: 責務が不明確になるため。
