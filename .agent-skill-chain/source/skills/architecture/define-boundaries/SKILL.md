# define-boundaries

**目的**: 責務・境界を定義し、02_設計の「責務」「参照関係」のたたき台を作る。

## 手順

1. 入力（01_要件定義、00_要求定義）を読む。
2. コンポーネント・モジュール・ファイルの「担当範囲」を 1 文ずつ定義する（単一責任）。
3. 境界（どこまでがこの責務で、どこからが他か）を明示する。
4. 参照関係（A は B を参照する）を 1 行ずつリスト化する。循環を避ける。
5. 出力を 02_設計の「責務」「境界」「参照関係」に反映する。

## 制約・禁止

- 1 コンポーネント 1 責務。CONCEPTS の単一責任に従う。
- 参照は「〇〇は △△ を参照」の 1 行に限定。長文で説明しない。
- 02 に書く内容の正本は 02 のみ。01 や 03 に設計の長文を重複させない。

## 成果物の形式

- **OUT**: 責務一覧。境界の説明（短文）。参照関係の表またはリスト。02_設計に貼れる形。design-api-contract ではこの責務・境界を前提に API を切る。
