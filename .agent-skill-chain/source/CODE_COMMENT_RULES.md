# CODE_COMMENT_RULES.md — コメント/docstring の参照規約

**責務**: コード中のコメント/docstring から**外部ドキュメントへの参照**（仕様名・章節番号・PR/issue/タスク番号）を禁止し、**コードファイル/シンボルへの参照**（grep で追跡可能なもの）のみを許可する。正本は本ファイル 1 か所。配線は索引のみ（CORE.md §境界）。

---

## 1 目的（陳腐化防止・正本1か所と整合）

外部ドキュメント名・章節番号・PR/issue/タスク番号をコメントに直書きすると、参照先のリネーム・章番号の繰り上がり・issue クローズによって**コメントだけが陳腐化**し、読み手を誤った正本へ誘導する。本規約は「コメントは grep で追跡できるコード内参照に限る」ことで、正本1か所（CORE.md §境界）の原則をコードコメント層でも保つ。

---

## 2 禁止（外部参照）

コメント/docstring に次を記述しない。

- **仕様ドキュメント名**: `XXX.md` / `XXX.adoc` 等のドキュメントファイル名（コメント本文での参照。コードの import/require/include 行は対象外）。
- **章節番号**: `§3.2` / `第4節` / `セクション 5` / `section 2.1` 等、ドキュメントの章・節・条への番号参照。
- **PR/issue/タスク番号**: `PR #123` / `Issue #42` / `チケット 100` / `タスク #7` 等の追跡番号、および裸の `#NN`（追跡番号を意図したもの）。
- **作業用 issue フォルダへのパス参照**: 作業用 issue フォルダ（既定は消費者標準 `.agent-skill-chain/runtime/{issue}/`、`.agent-skill-chain/project/` で作業用 issue フォルダの場所を上書きしている場合はその場所。ただし `close/` 配下は完了後の永続パスのため除く）への直接パス参照。issue 完了時の `close/` 移動でパスが変わりうるため、コメントに書くと陳腐化する（[DOCS_NOISE_RULES.md (iv-b)](DOCS_NOISE_RULES.md) と対称の理由。§3 の「他コードファイルへの参照」許可には含まれない）。

---

## 3 許可（コード参照=grep 追跡可）

次は**許可**する。リネーム時に grep で機械的に追従でき、陳腐化を検出できるため。

- **他コードファイルへの参照**: ファイルパス・モジュール名（`foo/bar.py`、`pkg.module`）。
- **シンボル参照**: 関数名・クラス名・メソッド名（`ClassName.method`、`build_index()`）。
- import/require/include 等の言語機能による依存記述（コメントではないコード行）。

> **注意（§2 との境界）**: 「他コードファイルへの参照」の許可は**通常のソースコードファイル**を指す。作業用 issue フォルダへのパス参照（§2）は、ファイルパスの形式であってもこの許可対象に**含まれない**。通常のコードファイルはリネームされても grep で追従できるが、作業用 issue フォルダは「フォルダごと `close/` へ移動する」という異なる陳腐化要因を持つため。

---

## 4 相互参照の張り替え（外部リンクはコア内対応へ）

既存コメントに外部参照が残っている場合は、(a) その情報をコードで表現できるならシンボル/ファイル参照へ張り替える、(b) 設計意図など文章での補足が必要なら**外部参照を伴わない自然文**に書き換える。ドキュメントとの対応はコメントではなく、設計ドキュメント側（02/03 等）でコード位置を指す方向に寄せる。

---

## 5 enforcement（CI grep 検出）

§2 の外部参照禁止は機械強制可能であり、CI（`enforcement/ci/audit.sh`）の grep 検出対象とする。検出ロジック・誤検出回避（コード参照を拾わない）の具体は enforcement 側で定義する。許可（§3）を誤検出しないこと。

---

## 汎用/固有境界

- **コア（本ファイル）**: 許可/禁止カテゴリの抽象規定。
- **`.agent-skill-chain/project/`（採用先で拡張）**: 言語別 docstring 慣習・禁止対象の具体パターン追加・追加 grep パターン。コアの許可/禁止カテゴリを上書きせず**拡張**する。
