# MODEL_TIER_RECOMMENDED.md — Claude 採用先向け 役割→推奨ティア（推奨デフォルト・advisory）

> **advisory（助言）である**: 本ファイルは Claude をオーケストレータ／ワーカーとして使う採用先**一般**に当てはまる、役割→抽象ティアの**推奨デフォルト**を示す。**必需物（mechanical necessity）ではなく助言**であり、`settings.enforce.json`・`plugin.json` のような Claude 動作上の必需設定とは根拠が異なる。
>
> **抽象原則への従属**: 本ファイルは [../../MODEL_SELECTION.md](../../MODEL_SELECTION.md) の抽象原則（適用条件・ティア明記義務・品質ゲート最上位固定・裁量の禁止と形骸化防止）に**従属**する。推奨デフォルトは抽象原則を**具体化した助言**であり、抽象原則を上書き・緩和しない。

---

## 1 責務

- Claude 採用先**一般**に当てはまる、役割→**抽象ティア**の**推奨デフォルト（advisory）**の正本。
- 本ファイルが持つのは「役割→抽象ティアの**方向性**」のみ。**世代付きモデル ID・本リポ固有の運用判断は持たない**（[§5 除外事項](#5-除外事項)）。
- 抽象原則（[../../MODEL_SELECTION.md](../../MODEL_SELECTION.md)）に従属し、それを具体化した助言に留まる。

---

## 2 適用条件

- 本推奨は、**モデルティアを選択できるランタイム（Claude ランタイム等）でサブ委譲を行うときのみ**適用する（[../../MODEL_SELECTION.md §1 適用条件](../../MODEL_SELECTION.md#1-適用条件)と同型）。
- ティア選択の概念が存在しない・解決できない**対象外環境**では発火せず、当該ランタイムの**既定動作**に従う。
- **推奨表がどこにも無い環境**（`project/` にも本ファイルにも表が無い）は、**ティア選択不能環境として MODEL_SELECTION §1 のランタイム既定動作へフォールバック**する。

---

## 3 優先順位での位置づけ

役割→ティアの解決順（勝つ順）は次で一意とする。

1. **`project/MODEL_TIER_TABLE.md`（採用先固有の確定運用）** — 最優先。
2. **本ファイル（platforms/claude 推奨デフォルト・advisory）** — 次点。
3. **[../../MODEL_SELECTION.md](../../MODEL_SELECTION.md)（PF 中立の抽象原則）** — 表を持たない。上記いずれの表も無ければ、§1 適用条件により**ランタイム既定動作**へフォールバックする。

本ファイルと MODEL_SELECTION はいずれも `source/` 配下であり、`project/` はその全 source（本ファイル含む）に優先する。

---

## 4 役割 → 推奨ティア表

> 列は「役割｜推奨ティア｜一般適用条件」の 3 列。**版番号付きの世代モデル ID（`<モデル名>-<世代番号>` 形式の文字列）は記載しない**（陳腐化耐性）。ティア呼称は Claude の抽象ティア（opus／sonnet／haiku）で表す。

| 役割 | 推奨ティア | 一般適用条件 |
| ---- | -------- | -------------- |
| 設計・レビュー・監査 | 上位ティア（opus） | 品質ゲート（レビュー・テスト・受け入れ基準）に直結する役割は上位ティアを推奨。格下げしない（[../../MODEL_SELECTION.md §3 品質ゲート最上位固定](../../MODEL_SELECTION.md#3-品質ゲート最上位固定)）。 |
| 実装 | 中位ティア（sonnet） | 標準的な実装は中位ティアを推奨。複雑な作業は上位ティアへエスカレーションする（[../../MODEL_SELECTION.md §4 未収束エスカレーション](../../MODEL_SELECTION.md#4-未収束エスカレーション)）。 |
| ログ記録専任（書記） | 軽量ティア（haiku） | ログ記録に専念する役割は軽量ティアを推奨。 |

各行は委譲パケットのティア根拠 1 行として引用できる粒度で書いている（[../../MODEL_SELECTION.md §2 ティア明記義務](../../MODEL_SELECTION.md#2-ティア明記義務)）。

## 5 除外事項

本ファイルは**一般推奨（advisory）に限定**する。次は**本ファイルに含めず** `project/`（採用先固有）に委ねる。

- **特定ティアの原則禁止方針**（例: fable の扱い）— 採用先の運用ポリシーであり一般推奨ではない。
- **ティア選定の順序規定**（例: 「上位ティア要否を先に判定し、不要時のみ中位ティアを選ぶ」という非裁量の選定手順）— 採用先固有の運用判断（ADR）に由来する。
- **降格（裁量下振れ）の計測閾値・承認フロー・対応表更新手順** — [../../MODEL_SELECTION.md §裁量の禁止と形骸化防止](../../MODEL_SELECTION.md#裁量の禁止と形骸化防止)に従い、具体値は `project/` に委ねる。
- **世代付きモデル ID** — 陳腐化耐性のため本ファイルは抽象ティア呼称までとし、モデル ID 解決は `project/` またはランタイム既定に委ねる。
