# 旧形式schemaの移行資料

ここにあるschemaはv0.4のデータ形式を記述する移行資料であり、v0.5 runtimeが読み込む入力schemaではない。v0.5の入力は[実行手順](../../v05/USAGE.md)と`src/`の実際のvalidatorに従う。

旧Step、Journal、staging、review export等の形式が存在しても、旧コマンドを実行したり、現行Evidenceとして受理したりしない。project契約の移行に必要な形式と、廃止する旧実行形式を分けて整理中である。

参照調査は[資産棚卸し](../../docs/reviews/v05_asset_inventory.json)に記録する。静的参照が無いことだけで、旧利用者のデータや禁止事項を削除する権限が得られるわけではない。
