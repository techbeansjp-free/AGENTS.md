## 確認完了後の対応

すべてのチェック項目を確認し、問題がないことを確認したら：

1. **各 Issue のレビュー書を更新**: 各 Issue のレビュー書の「動作確認」セクションに確認結果を記録
2. **Issue のステータスを更新**: 各 Issue のステータスを「完了」に更新
3. **次の Issue に進む**: 未完了の Issue に進む
