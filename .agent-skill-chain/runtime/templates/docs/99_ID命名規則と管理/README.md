# ID命名規則と管理

本システムのドキュメントでは、以下のID命名規則を使用しています。各IDは、ドキュメント内で一意に識別するための識別子として使用されます。

**重要**: 本ドキュメントは、IDの**一元管理表**として機能します。新しいIDを追加する際は、必ず本ドキュメントの該当する一覧表を更新してください。各ドキュメントでIDを定義する際は、本ドキュメントの一覧表を参照し、重複や不整合がないことを確認してください。

## 全数採番方針

本ドキュメントの一覧表を、プロジェクト内で使用する**全 ID の唯一の台帳**とします。

- 新規 ID を追加する際は、**必ず**本ドキュメントの該当する一覧表に登録してから使用してください（未登録のまま他ドキュメントで ID を使い始めることを禁止します）。
- 一覧表に**未登録**の ID がドキュメント内で使用されている場合は、監査またはレビュー（[`.agent-skill-chain/source/DOCS_RULES.md`](../../../../../.agent-skill-chain/source/DOCS_RULES.md) §継続追随ゲート）で検出し、本ドキュメントへの追記を促してください。

## ID管理のルール

1. **新規ID追加時**: 新しいIDを追加する際は、必ず本ドキュメントの該当する一覧表を更新してください
2. **ID定義時**: 各ドキュメントでIDを定義する際は、本ドキュメントの一覧表を参照し、重複や不整合がないことを確認してください
3. **ID変更時**: IDを変更する際は、本ドキュメントの一覧表と、該当するすべてのドキュメントを更新してください
4. **ID削除時**: IDを削除する際は、本ドキュメントの一覧表から該当IDを削除してください（ただし、過去のドキュメントとの整合性を保つため、削除は慎重に行ってください）
