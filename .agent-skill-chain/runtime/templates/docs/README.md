# システム仕様書

## ドキュメント構成

本システム仕様書は、以下のセクションで構成されています。

1. **[システム概要](./01_システム概要/README.md)**
   - システムの全体像、構成、業務フローを定義
2. **[画面設計](./02_画面設計/README.md)**
   - 画面の動きと、各画面の項目を定義
3. **[データ設計](./03_データ設計/README.md)**
   - ER図とテーブル定義を定義
4. **[機能設計](./04_機能設計/README.md)**
   - 複雑なロジックやバッチ処理を定義
5. **[エラー処理と外部通知](./05_エラー処理と外部通知/README.md)**
   - 共通エラー処理・報告の一箇所化・二重防止・外部通知（Rollbar/Slack 等）の設計方針
6. **[ID命名規則と管理](./99_ID命名規則と管理/README.md)**
   - システムドキュメントで使用するIDの命名規則と一元管理（全数採番方針）

また、以下の構成要素も本システム仕様書に含まれます。

- **[01_システム概要/05_規約](./01_システム概要/05_規約/README.md)** — コーディング規約・ディレクトリ構成・アーキテクチャ等のドメイン別規約索引（greenfield プロジェクトの必須文書化先）。
- **[00_review](./00_review/README.md)** — システム仕様書のレビュー記録索引（継続追随ゲートの記録先）。

## ドキュメントの読み方

### 対象読者

- **開発者**: 実装の詳細を理解するため
- **プロジェクトマネージャー**: 進捗管理と品質確認のため
- **クライアント**: システムの機能と仕様を理解するため

### 記述ルール

- **Mermaid 図**: システム構成、フロー、ER図などを視覚的に表現
- **表**: 画面項目、テーブル定義などを構造化して記述
- **Markdown**: テキストベースで記述し、Git でバージョン管理

### 更新履歴

更新履歴の各行は、可能な限り対応するレビュー記録（[00_review/](./00_review/README.md) 配下の `YYYYMMDD_HHMMSS_review.md`）へリンクしてください。継続追随ゲート（[`.agent-skill-chain/source/DOCS_RULES.md`](../../../../.agent-skill-chain/source/DOCS_RULES.md) §継続追随ゲート）に従い、実装変更を伴う更新は版番号・変更内容・レビュー記録の 3 点を相互に参照できる状態を保ちます。

| 日付       | バージョン | 更新内容 | 更新者 | 対応レビュー記録 |
| ---------- | ---------- | -------- | ------ | ----------------- |
| YYYY-MM-DD | 1.0.0      | 初版作成 | -      | -                 |
