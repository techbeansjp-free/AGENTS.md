# 5. 規約

greenfield プロジェクト（開発環境・規約が未整備な段階）では、コーディング規約・ディレクトリ構成・アーキテクチャを本セクション配下に文書化することが必須です（[DOCS_RULES.md](../../../../../../.agent-skill-chain/source/DOCS_RULES.md) 参照）。`docs/` を採用しないプロジェクトには課しません。

## 必須の骨格 と 任意の拡張

- **必須**: 本 README（カテゴリ一覧）と [00_索引と探し方/README.md](./00_索引と探し方/README.md)（探し方索引）の 2 ファイル。小規模プロジェクトはこの 2 ファイルのみで開始してよい。
- **任意の拡張**: `10`〜`90` の各ドメイン別 README は、プロジェクトの規模・必要性に応じて拡張する。未使用のドメインは骨格プレースホルダのまま残してよい（過剰な器を強いない）。

## 決定・ADR 記録との関係

これらの規約をどう決めたか（採否・比較・根拠）の記録は本 README・各ドメイン README ではなく、[EVIDENCE_POLICY.md §節5](../../../../../../.agent-skill-chain/source/EVIDENCE_POLICY.md) が定める ADR 形式で記録する（本ファイルは決定内容の文書化先であり、決定プロセスの正本ではない）。
