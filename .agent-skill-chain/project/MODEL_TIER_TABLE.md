## opus 要否判定チェックリスト

実装（および本表で「opus 要否判定に従う」と指定した役割）を委譲する前に、**まず「opus で実行させるべきか」を下記チェックリストで判定する**。opus が不要と確定した場合に**限り** sonnet を選ぶ。「sonnet をデフォルトにしておき、複雑だと判明した時だけ opus に格上げする」という**逆順の運用にはしない**。

1. 複数コンポーネント／複数フェーズへ横断的に影響するか
2. 公開 I/F・契約・スキーマ・enforcement・セキュリティ/権限/課金に触れるか
3. 後戻りコストが高いか（データ移行・破壊的変更・不可逆操作）
4. 要件が曖昧で設計判断を多く含むか
5. 同種タスクで過去に sonnet が収束しなかった実績があるか

→ **1 つでも「はい」なら opus、すべて「いいえ」なら sonnet**。判定結果と該当番号（例: 「該当2・4によりopus」）を TIER_RATIONALE に 1 行で記録する。これは目安のチェックリストであり絶対閾値ではないが、判定観点と結果を記録することで事後監査を可能にする（非裁量性の担保）。

このチェックリストは、下表で「opus 要否判定に従う」と指定した役割（実装・要求要件執筆・issue 起票・調査・デフォルト等）に共通する判定機構であり、役割ごとに別基準を重複定義しない。

## 品質最優先・コスト二次

ティア選定はコスト最適化のために行うが、品質ゲート（レビュー・テスト・受け入れ基準）を最上位に固定する。コスト都合で品質ゲートを下げない（[../source/MODEL_SELECTION.md §3 品質ゲート最上位固定](../source/MODEL_SELECTION.md#3-品質ゲート最上位固定)）。安価ティアで品質が満たせない場合は上位ティアへ上げる。

## 裁量禁止との整合（非裁量ルールである旨）

**opus 要否先行検討は、対応表の該当行の決め方そのものであり、エージェントの自由裁量ではない。** 「迷ったら上位」という裁量上振れとは区別される非裁量の選定手順である。詳細な検討経緯・論拠は [docs/maintainer/workflow/close/20260712_120018_モデルティア選定方針のproject化/00_要求定義.md](../../docs/maintainer/workflow/close/20260712_120018_モデルティア選定方針のproject化/00_要求定義.md)（close 済み。読めなくても本表の結論の理解には支障がない補足参照）を参照。この整合の一般原則は [../source/MODEL_SELECTION.md §裁量の禁止と形骸化防止](../source/MODEL_SELECTION.md#裁量の禁止と形骸化防止) に定める。

### 降格（裁量下振れ）は当面認めない（凍結）

コスト都合による裁量的な降格（裁量下振れ）は、**当面認めない（凍結）**。降格を行うための計測閾値・承認フロー・対応表更新手順は、現時点では本ファイルに定義しない。将来的に降格運用を導入する場合は、本節を改訂して具体の計測閾値・承認フロー・対応表更新手順を**本ファイルに追記した時点で初めて有効化**する（凍結解除には本ファイルの改訂そのものが必要であり、他ファイルへの再委譲では発動しない）。[../source/MODEL_SELECTION.md §裁量の禁止と形骸化防止 2](../source/MODEL_SELECTION.md#裁量の禁止と形骸化防止) は本節を参照先として指すのみで、降格手続きの実体は持たない（source↔project の循環参照を避けるため、実体は本ファイル側に一方向で置く）。

## 未収束エスカレーション

[../source/MODEL_SELECTION.md §4 未収束エスカレーション](../source/MODEL_SELECTION.md#4-未収束エスカレーション)が project へ委ねる具体段階・閾値を本節で定める。エスカレーションは「収束しない」という条件で発火する非裁量の手続きであり、閾値未達での任意のエスカレーションは§裁量禁止（上振れ）に抵触する。

- **通常閾値**: 同一の指摘・課題が**2 ラウンド**（レビュー→修正→再レビューを 2 回）経ても解消しない場合、次ラウンドから**1 段上位のティアへエスカレーション**する（例: sonnet → opus）。エスカレーション後のティアと理由（「2ラウンド未収束によりエスカレーション」等）を TIER_RATIONALE に明記する。
- **監査役の即時エスカレーション**: 監査・レビュー・verify-and-close 等の**品質ゲート相当役割**を担うサブに限り、2 ラウンドの閾値を待たず**即座に 1 段上位ティアへエスカレーション**してよい（[§品質最優先・コスト二次](#品質最優先コスト二次)を優先する）。
- 上位ティアへエスカレーションしてもなお収束しない場合は、対応表の最上位（opus）で据え置き、進行役（人間判断）へエスカレーションする。
