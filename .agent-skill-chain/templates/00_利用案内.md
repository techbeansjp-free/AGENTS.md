# template利用案内

## 目的

このdirectoryは成果物の汎用構造を提供する。templateは作業手順やproject固有規則の正本ではなく、対応するskillから選択して使用する入力枠である。

## ownerと編集

packageが所有する。必須欄を追加・変更するときは、対応skill、受け入れ条件、仕様、testを同じ変更単位で更新する。利用projectは複製後の成果物を所有する。

## 使い方

| directory | 入口 | 用途 |
|---|---|---|
| `common/` | [02_利用案内.md](common/02_利用案内.md) | 図表・識別子を必要時だけ判断する補助guide |
| `issue/` | [12_利用案内.md](issue/12_利用案内.md) | 要求、要件、設計、計画、review、PR成果物 |
| `specs/` | [00_利用案内.md](specs/00_利用案内.md) | 利用projectが所有する`docs/specs/`の初期構成 |

先に現在の[Step skill](../skills/00_利用案内.md)を読み、そこから指定されたtemplateだけを全文読む。仕様一式の初期生成ではproject kindに応じて適用categoryを選ぶ。

## 置かないもの

完成済み成果物、repository固有値、test結果、review証拠、秘密情報を置かない。templateにないことを禁止と解釈せず、手順をtemplateだけから推測しない。

## 正本

選択手順は各`SKILL.md`、成果物の構造は対応template、完成後の内容は利用projectのIssueまたは`docs/specs/`を正本とする。
