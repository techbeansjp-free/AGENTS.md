# テスト標準

## 共通既定値

- 単体・結合・E2Eの全テストを、日本語の`Feature / Scenario / Given / When / Then`で起票する。
- 各Scenarioへ一意のSCN IDを付け、要件、実装、結果へ追跡する。
- 期待する失敗を先に確認し、最小実装で合格させた後に整理する。
- 正常、失敗、境界、悪用、ロールバックを扱う。
- テストは実workspace、実remote、他worktreeを変更・削除しない。

| 層 | 所有する責務 | 禁止事項 | コマンド |
|---|---|---|---|
| 単体 | 純粋規則、状態遷移、境界値 | 実ネットワーク・実Git更新 | {コマンド} |
| 結合 | ファイル、責務間、模擬外部境界 | 実利用環境の変更 | {コマンド} |
| E2E | 利用者操作から最終結果 | 実remoteへの破壊操作 | {コマンド} |
