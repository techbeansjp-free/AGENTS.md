# テスト標準

## 共通既定値

- project policy選択の言語、runner、test layerで実行可能な受け入れ例を作る。
- 各実行可能ACへrepository全体で一意な安定`SCN ID`を1件割り当てる。重複・欠落を拒否し、`requirement/AC → SCN ID → project選択test layer → runner command/result → immutable evidence`を同じbindingで追跡する。
- 期待する失敗を先に確認し、最小実装で合格させた後に整理する。
- 正常、失敗、境界、悪用、ロールバックを扱う。
- テストは実workspace、実remote、他worktreeを変更・削除しない。

| project policyの選択層 | 所有する責務 | 安全境界 | コマンド |
|---|---|---|---|
| {選択されたtest layer} | {その層が担保する契約} | {隔離する実環境・外部状態} | {選択されたrunner command} |
