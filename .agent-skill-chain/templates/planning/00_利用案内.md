# 計画template利用案内

## 目的

このdirectoryは、複数タスクを束ねる計画単位の雛形を置く。**規律そのものは置かない。** 起票時点と計画単位の規則は[開発ワークフロー](../../docs/01_開発ワークフロー.md#起票時点と計画単位)が唯一所有し、ここへ複製しない。

## ownerと編集

packageが所有する。利用projectは雛形を自分のGit管理下へ複製し、期間、tracker、タスクIDといったproject固有値を複製先へ書く。**package内のtemplate自体へproject値を書かない。**

## 使い方

| file | 用途 |
| ---- | ---- |
| [01_計画単位.md](01_計画単位.md) | 1つの計画単位のMVP、完了条件、対象外、タスク表、依存を記録する |

複製先は利用projectが決める。`docs/`配下が一般的だが、packageは場所を指定しない。

計画単位の長さは既定1週間で、利用projectが変更できる。判断基準は開発ワークフローが持つ。

## 置かないもの

- 進捗、担当、優先度、開始日、完了日。これらは外部trackerが正本であり、ここへ複製すると二重管理になる。
- 起票時点や計画期間の規則本文。開発ワークフローが唯一所有する。
- 特定のproject名、期間、GitHub Project番号、採番済みタスクID。
- sprintの採用を前提とする記述。計画単位はsprintと同義ではない。
