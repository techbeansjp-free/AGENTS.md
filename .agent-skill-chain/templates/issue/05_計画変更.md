# 05 計画変更

> 承認済み計画（fullは00〜03、quick/pocは00）は、fullのStep 8、quick/pocのStep 4の記録時に計画封印され、以後は書き換えない。封印後に計画を変える場合だけ、この文書の末尾へ`AMD-NNN`を1件追記する。既存entryは編集・削除・並べ替えしない。実装事実はGit、現在のsystem契約は`docs/specs/`が所有し、ここへ複写しない。

| 読者 | 読む節 |
|---|---|
| 発注・評価する人 | 各entryの対象・After・理由 |
| 実装・レビューする人 | 全entry |
| 運用する人 | 各entryの影響範囲 |

`AMD-001`から欠番・重複なく昇順に採番し、6項目をすべて記入する。`workflow record`のStep 9・10、`pr create`、`pr merge`が見出しと項目を検査する。

## AMD-001 （変更の要約）

- 対象: （封印済み文書と節。例: 03_実装計画.md T02）
- Before: （封印時の記述）
- After: （変更後の計画）
- 理由: （変更を必要にした事実）
- 影響する契約: （AC・要件・設計判断のID。無ければ「なし」）
- 影響範囲: （影響するtask・file・test）
