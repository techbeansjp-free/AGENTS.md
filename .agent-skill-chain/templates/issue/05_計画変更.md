# 05 計画変更

> 承認済み計画（fullは00〜03、quick/pocは00）は書き換えない。計画を変えるのは、目的・受け入れ条件・不変条件・scope・security境界・公開interfaceや外部契約・data互換性・不可逆操作のいずれかが変わる場合だけであり、そのときこの文書の末尾へ`AMD-NNN`を1件追記する。それ以外の実装上の判断（関数名、分割、helper、library、test構成、file配置など）はGitに残せば足り、ここへ書かない。変更前の記述は承認済み計画から、影響範囲は`impact`から導出できるため書かない。既存entryは編集・削除・並べ替えしない。

`AMD-001`から欠番・重複なく昇順に採番し、3項目を記入する。

## AMD-001 （変更の要約）

- 対象: （変わる契約。例: AC-004、INV-02、03_実装計画.md T02）
- 変更: （変更後の計画）
- 理由: （変更を必要にした事実）
