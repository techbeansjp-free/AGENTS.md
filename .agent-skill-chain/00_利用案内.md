# ASC v0.5 の契約入口

- [運用ポリシー](docs/00_運用ポリシー.md)：Goal、権限、作業境界。
- [実行モデル](docs/01_開発ワークフロー.md)：必要な作業の選択と再開。
- [品質基準](docs/02_品質基準.md)：独立レビュー、検証、性能。
- [製品の実行手順](../v05/USAGE.md)、[Skill](../skills/asc/SKILL.md)。

旧Step用Hook・Skillは現行treeに存在しない。`project-policy.json`、`project/`、`policy/`にはbase側品質契約の移行用資産が残る。これはv0.5 runtimeの入口ではなく、利用者へ配布しない。契約検査の移行が済むまでは無断で削除・緩和しない。

`tmp/`、`local/`、runtime記録はGit管理外の個別資産であり、製品置換を理由に削除しない。過去の実装・規約はGit履歴から参照する。

仕様書の任意テンプレートは[v0.5仕様書テンプレート](../v05/templates/specs/00_利用案内.md)を利用する。旧Step専用テンプレートは継承しない。
