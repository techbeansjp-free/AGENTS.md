# ステップ2: 要件定義

入力は`full`モードの要求。成果物はユーザーストーリー、ユビキタス言語、ドメインモデル・不変条件、機能・非機能要件、受け入れ条件、Gherkin IDを含む`01_要件定義.md`。要件を観測可能にし、権限境界を明示する。ステップ3へ合成する。

## テンプレート契約

作業開始前に[01_要件定義.md](../../templates/issue/01_要件定義.md)を全文読み、その見出し構造と必須欄を使ってステージング内の`01_要件定義.md`を作る。独自構成で再作成せず、該当しない欄は理由付きで扱う。
