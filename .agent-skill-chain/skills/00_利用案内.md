# Step skill利用案内

## 目的

このdirectoryは開発フローのStep 0〜11を、1 directoryにつき1つの`SKILL.md`として提供する。また、hostから正本へ誘導する共通登録アダプター`asc-step/SKILL.md`を所有する。AIは成果物名から手順を推測せず、該当skillを開始前に全文読む。

## ownerと編集

packageが所有する。各`SKILL.md`の`name`はdirectory名と一致させ、単一責務、入力、出力、停止条件、template契約を保つ。Step追加・削除・順序変更は[開発ワークフロー](../docs/01_開発ワークフロー.md)とbuild検査を同時に変更する。

| Step | skill |
|---:|---|

| 2 | [要件定義（step-02-requirements）](step-02-requirements/SKILL.md) |
| 3 | [要求・要件レビュー（step-03-requirements-review）](step-03-requirements-review/SKILL.md) |
| 4 | [耐久トラッカー同期（step-04-issue-sync）](step-04-issue-sync/SKILL.md) |
| 5 | [詳細設計（step-05-design）](step-05-design/SKILL.md) |
| 6 | [実装計画（step-06-plan）](step-06-plan/SKILL.md) |
| 7 | [設計・計画レビュー（step-07-design-review）](step-07-design-review/SKILL.md) |
| 8 | [設計同期（step-08-design-sync）](step-08-design-sync/SKILL.md) |
| 9 | [実装（step-09-implement）](step-09-implement/SKILL.md) |
| 10 | [実装レビュー（step-10-review）](step-10-review/SKILL.md) |
| 11 | [PR作成（step-11-pr）](step-11-pr/SKILL.md) |

Claude Codeは`.claude/skills/asc-step/SKILL.md`、Codexは`.agents/skills/asc-step/SKILL.md`から同じ`asc-step`正本へ入る。`asc-step`はStep契約を複製しない登録口である。現在のStepを[開発ワークフロー](../docs/01_開発ワークフロー.md)で特定し、上表の`SKILL.md`を全文読んでから、そのskillが指定するtemplateだけを読む。

## 置かないもの

project固有コマンド、固定runner、固定言語、repository固有ruleを置かない。複数Stepの責務を1つのskillへまとめず、template本文をskillへ複製しない。

## 正本

Stepの順序とmodeは[01_開発ワークフロー.md](../docs/01_開発ワークフロー.md)、各Stepの実行契約は各`SKILL.md`、成果物の書式はskillからリンクされたtemplateを正本とする。
