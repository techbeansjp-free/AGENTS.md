# ステップ3: 要求・要件レビュー

入力は対象文書のダイジェストと00/01。成果物は肯定・敵対の全評価項目を含む単一`04_レビュー.md`。ラウンド1で指摘を確定し、ラウンド2・3は有限契約に従う。指摘なしの承認を有効とする。Medium/Lowは自動反復を起こさない。Critical/High解消または別権限者による受容後だけ同期する。

## テンプレート契約

作業開始前に[成果物用語と責務境界](../../docs/01_開発ワークフロー.md#成果物用語と責務境界)を全文読み、要求と要件の責務越境、暗黙の再定義、追跡切れをfindingにする。

作業開始前に[04_レビュー.md](../../templates/issue/04_レビュー.md)を全文読み、その見出し構造と評価欄を使って単一の`04_レビュー.md`を作る。修正する00/01はそれぞれの作成時に選択したテンプレート構造を維持する。
