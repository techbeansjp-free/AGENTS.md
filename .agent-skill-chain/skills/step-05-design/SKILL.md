# ステップ5: 詳細設計

入力は耐久トラッカーへ同期済みの`full`要件。成果物は境界づけられたコンテキスト、依存方向、明示的なコマンドの入力・出力、信頼境界、承認、原子性、失敗、復旧、ロールバック、仕様影響、テスト接合部を記載した`02_設計.md`。Mermaid・UUIDは必要時だけ設計し、ADRリンクは任意の拡張メタデータだけとする。

## テンプレート契約

作業開始前に[02_設計.md](../../templates/issue/02_設計.md)を全文読み、その見出し構造と必須欄を使って`02_設計.md`を作る。条件付きの図表・識別子ガイドは、このテンプレートから指示された場合だけ読む。
