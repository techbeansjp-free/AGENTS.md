# 自己拡張ワークフロー（このリポジトリ固有・最優先）

**目的**: 本リポジトリは「パッケージの正本」かつ「自己拡張（ドッグフーディング）する消費者」の二役を兼ねる。両者は git の扱いが逆になるため、名前空間を分離して二重管理・配布物汚染を防ぐ。

このファイルは `.agents-project/` 配下にあり、**`.agents/` および CLAUDE.md の標準フローより優先**される（[../.agents-project/README.md](README.md) §優先順位）。

## issue の作成場所（標準フローの上書き）

CLAUDE.md / `.agents/` の標準では issue を `.workflow/<timestamp>_<title>/` に作るが、**本リポジトリでは下記に作成する**。

| 種別 | 作成場所 |
|------|----------|
| 単一 issue | `docs/maintainer/workflow/<timestamp>_<title>/` |
| サブ issue（PR 指摘対応等） | `docs/maintainer/workflow/{parent}/90_issues/{ディレクトリ名}/` |

- `<timestamp>` は実行環境の現在時刻（JST）。例: `TZ=Asia/Tokyo date +%Y%m%d_%H%M%S`。
- ファイルセット（`00_要求定義.md`・`01_要件定義.md`・`02_設計.md`・`03_実装計画.md`・`04_review.md` 等）は `.workflow/templates/` の標準テンプレートに従う。
- これらは **git 追跡対象**であり、自己拡張の開発記録として残す。

## 理由（名前空間の役割分担）

| パス | 役割 | git |
|------|------|-----|
| `.agents/`、`AGENTS.md`、`CLAUDE.md`、`.workflow/templates/`、`.claude-plugin/`、`.agents/scripts/` | パッケージ正本（配布物） | 追跡する |
| `docs/maintainer/workflow/` | 自己拡張 issue（保守者の開発記録） | 追跡する |
| `.workflow/<issue>`、`.workflow/workflow.db*` | 消費者ランタイム生成物 | **無視**（`.gitignore`） |
| `.claude/`、`.adapters/` | setup / build による各ツール向け生成物 | **無視**（`.gitignore`） |

参照: [../docs/maintainer/workflow/README.md](../docs/maintainer/workflow/README.md)、[../.agents/SETUP.md](../.agents/SETUP.md)、ルート `.gitignore`。
