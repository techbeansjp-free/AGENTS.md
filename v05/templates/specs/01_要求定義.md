# 要求定義（入口）

> 値を書かない入口。書く内容ごとに`details/`の正本を示す。置き場の規則は[利用案内](00_利用案内.md#置き場の表)に従う。小さな変更は、Issue・PRに要求と受入条件を書けば足りる。仕様書は作らない。

| 書く内容 | 書く場所 |
|---|---|
| 元要求・依頼者、背景・解決する課題、Goal・成功指標 | [システム概要](details/01_システム概要/00_概要.md)「背景と目的」 |
| 利用者・関係者（目的・ロール） | [システム概要](details/01_システム概要/00_概要.md)「利用者・関係者」。権限は[信頼境界・認証認可](details/10_セキュリティ/01_信頼境界・認証認可.md) |
| 対象範囲・対象外、制約・前提（既存契約・環境・期限・予算） | [制約・前提・対象外](details/02_要件/02_制約・前提・対象外.md) |
| 業務・利用シナリオ（開始条件・操作・完了条件・例外） | [業務・利用者フロー](details/01_システム概要/01_業務・利用者フロー.md) |
| 未確定事項（確認先・判断待ちの内容・影響） | [システム概要](details/01_システム概要/00_概要.md)「未決事項」 |
| 状態（提案／承認済み、確認者と根拠） | 各文書の冒頭の1行（[利用案内](00_利用案内.md#書き方)） |
