# 詳細設計（入口）

> 値を書かない入口。書く内容ごとに`details/`の正本を示す。置き場の規則は[利用案内](00_利用案内.md#置き場の表)、書き方は[同じく](00_利用案内.md#書き方)に従う。小さな変更は、Issue・PRに要求と受入条件を書けば足りる。仕様書は作らない。

| 書く内容 | 書く場所 |
|---|---|
| 目的・関連要件、処理（正常・代替・失敗）、失敗時の状態・副作用 | [個別機能仕様](details/04_機能/01_個別機能テンプレート.md)。主体は[システム概要](details/01_システム概要/00_概要.md)「利用者・関係者」に書き、個別機能仕様にはACT IDだけを書く。前提は[制約・前提・対象外](details/02_要件/02_制約・前提・対象外.md)に書き、CON IDで参照する。状態遷移は[状態遷移](details/04_機能/02_状態遷移.md) |
| 入出力の型・形式・制約・秘密区分・エラー | APIは[個別API仕様](details/06_外部インターフェース/02_個別APIテンプレート.md)、保存するデータは[データ項目仕様](details/07_データ/02_データ項目テンプレート.md) |
| データ（モデル・整合性・migration） | [データモデル](details/07_データ/01_データモデル.md)、[データ項目仕様](details/07_データ/02_データ項目テンプレート.md)、[移行計画](details/13_移行・廃止/00_移行計画.md) |
| 保持・削除 | [データライフサイクル](details/07_データ/03_ライフサイクル.md) |
| 外部契約（正本・版・互換性・タイムアウト） | [API・外部連携共通契約](details/06_外部インターフェース/01_共通契約.md)、[個別API仕様](details/06_外部インターフェース/02_個別APIテンプレート.md)、[ファイル・イベント連携](details/06_外部インターフェース/03_ファイル・イベント連携.md) |
| 同時実行・再試行（競合・原子性・冪等性） | 保存の競合は[データ項目仕様](details/07_データ/02_データ項目テンプレート.md)「整合性と更新」、通信の再試行・冪等性は[共通契約](details/06_外部インターフェース/01_共通契約.md) |
| 認証・認可・入力検証 | [信頼境界・認証認可](details/10_セキュリティ/01_信頼境界・認証認可.md) |
| 対応するテスト | [要件追跡表](details/15_要件追跡/00_追跡表.md) |

コードやスキーマに正本がある定義は参照し、全文を重複させない。
