# 基本設計（入口）

> この文書は値を書かない入口である。書く内容ごとに、`details/`の正本を示す。置き場の規則は[利用案内](00_利用案内.md#置き場の表)に従う。小さな変更は、Issue・PRに要求と受入条件を書けば足り、仕様書を作らない。

| 書く内容 | 書く場所 |

| 関連要求・要件 | [要件一覧](details/02_要件/00_要件一覧.md)のIDで参照する |
| 既存設計の再利用、構成要素（責務・入出力・依存・障害時の振る舞い）、設計判断 | [全体アーキテクチャ](details/03_アーキテクチャ/00_全体構成.md) |
| 外部の依存先と障害時の縮退 | [システムコンテキスト](details/03_アーキテクチャ/01_システムコンテキスト.md) |
| 業務概念・用語・境界 | [用語・略語](details/01_システム概要/02_用語・略語.md)、不変条件は[業務規則](details/01_システム概要/01_業務・利用者フロー.md) |
| セキュリティ（保護資産・信頼境界・認可・脅威と対策） | [セキュリティ方針・資産](details/10_セキュリティ/00_セキュリティ方針・資産.md)、[信頼境界・認証認可](details/10_セキュリティ/01_信頼境界・認証認可.md)、[脅威・対策・監査](details/10_セキュリティ/02_脅威・対策・監査.md) |
| 統合・変更影響（API・DB・画面・外部依存・互換性） | [API・外部インターフェース一覧](details/06_外部インターフェース/00_インターフェース一覧.md)、[個別画面仕様](details/05_画面/02_個別画面テンプレート.md)、[データ一覧](details/07_データ/00_データ一覧.md)、[互換・廃止](details/13_移行・廃止/01_互換・廃止.md) |
| 未決事項 | [システム概要](details/01_システム概要/00_概要.md)「未決事項」 |

必要なら構成図やシーケンス図を追加する。特定の層構造や専用コンポーネントの新設は必須ではない。
