## レビュー概要

CodeRabbit が **Nitpick** をレビュー本体（Review body）に「🧹 Nitpick comments (N)」として記載するため、レビューコメント API のみでは取得できず指摘が漏れる事象を受けて、**汎用版** `AGENTS_GITHUB_PR_REVIEW_FETCH.md` に「Nitpick 取得漏れ防止」を必須対応策として追記しました。

### 追加・変更された内容

1. **クイックリファレンス**

   - 項目 6 を新設: Nitpick 取得漏れ防止（必須）— レビュー本体（reviews の body）の取得とパース
   - 旧 6・7 を 7・8 に繰り下げ

2. **新セクション「5.5 CodeRabbit の Nitpick 取得漏れ防止（必須対応策）」**

   - 背景・原因: レビューコメント API はインラインのみ。Nitpick はレビュー body に記載されるため漏れる
   - 対応策: レビューコメントに加えて reviews を取得し、body をパースして Nitpick/Minor を指摘一覧に含める
   - GitHub CLI の場合は `pulls/{number}/reviews` を必ず実行
   - 禁止事項: レビューコメントのみ取得、指摘一覧を Nitpick 確認せず確定

3. **LLM エージェント向け実行ルール「4. コメントとレビューの取得ルール」**

   - Nitpick 取得漏れ防止（必須）の追記
   - 禁止事項に「レビューコメントのみ取得」「body 確認せず指摘一覧確定」を追加

4. **処理フロー（Mermaid）**

   - STEP5 に「必須: Nitpick は body に記載」を追記
   - STEP5B を追加: レビュー body のパースで Nitpick/Minor を指摘一覧に追加

5. **AI 自己チェックリスト**

   - レビュー本体（reviews）の取得の有無
   - Nitpick のパースを指摘一覧に含めているか

6. **よくあるエラーと対処法**

   - エラー 5: 指摘漏れ（Nitpick が指摘一覧に含まれていない）— 原因・対処法・遵守の明記

7. **最後に（人間向け）**

   - 手順 5 として「レビューコメントとレビュー（reviews）の両方の取得」「body パースで Nitpick を指摘一覧に含める」を追加。手順番号を 6→7、7→8 に変更

8. **最終更新日**
   - 2026 年 2 月 5 日（Nitpick 取得漏れ防止を必須対応策として追記。汎用版）
