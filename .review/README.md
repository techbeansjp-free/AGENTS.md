# レビューディレクトリ

このディレクトリには、**AGENTS 規約とテンプレート全体のレビュー結果**を時系列で管理します。

> **重要**: このディレクトリのレビューは、**issue/タスクごとのレビュー（`04_review.md`）とは異なります**。
>
> - **`.review/`**: AGENTS 規約とテンプレート全体のレビュー（このディレクトリ）
> - **`04_review.md`**: 各 issue/タスクの実装完了後のレビュー（`.workflow/{YYYYMMDD_HHMMSS_issue_name}/04_review.md`）

---

## 目的

このディレクトリは、以下の目的で使用します：

1. **AGENTS 規約のレビュー**: 規約ドキュメント（`AGENTS.md`、`.agents/実行ルール.md`、`.agents/サブエージェント抜かし防止.md` 等）の整合性や改善点の記録
2. **テンプレートのレビュー**: テンプレートファイル（`.workflow/templates/`）の整合性や改善点の記録
3. **ワークフローのレビュー**: ワークフロー全体の有効性や改善点の記録（フェーズ順に 4.5 ドキュメント徹底レビューを含む）
4. **AI エージェントの動作確認**: AI エージェントが規約に従って正しく動作するかの確認

---

## ファイル命名規則

レビューファイルは以下の形式で命名します：

```
YYYYMMDD_HHMMSS_レビュー内容.md
```

**命名例**:

- `20251123_123000_AGENTS規約とテンプレートレビュー.md`
- `20251201_143000_テンプレート更新レビュー.md`
- `20251215_091500_ワークフロー改善レビュー.md`

**注意**: 同じ日に複数のレビューを実施する可能性があるため、日時（`YYYYMMDD_HHMMSS`）をプレフィックスとして使用します。これにより、ファイル名の重複を防ぎ、時系列での管理が容易になります。

## AI エージェント向けの注意事項

> **⚠️ 重要**: LLM エージェント（AI）は、このディレクトリのレビューファイルを**参照のみ**として使用してください。

### AI エージェントが守るべきこと

1. **参照のみ**: `.review/`ディレクトリのレビューファイルは、過去のレビュー結果を参照するために使用します。新しいレビューは原則として人間が作成します（ユーザー指示に基づく AI 作成は「AI エージェントが守るべきこと」4 を参照）。

2. **`04_review.md`との区別**:

   - `.review/`のレビュー: AGENTS 規約とテンプレート全体のレビュー（このディレクトリ）
   - `04_review.md`: 各 issue/タスクの実装完了後のレビュー（`.workflow/{YYYYMMDD_HHMMSS_issue_name}/04_review.md`）

3. **ワークフローでの使用**: AI エージェントは、通常のワークフロー（00 → 01 → 02 → 03 → **4.5 ドキュメント徹底レビュー** → 実装 → 04_review）で `04_review.md` を作成・更新します。`.review/`ディレクトリのレビューファイルは、規約やテンプレートの改善時に参照するためのものです。

4. **「参照のみ」の例外**: ユーザー指示に基づき、規約・テンプレート改善の一環として AI が `.review/` にレビューファイルを新規作成する運用は許容します。その場合も本 README の命名規則とレビュー一覧への追加に従ってください。

### AI エージェントが参照すべきファイル

- **通常のワークフロー**: `.workflow/{YYYYMMDD_HHMMSS_issue_name}/04_review.md` を作成・更新
- **規約・テンプレートの改善時**: `.review/`ディレクトリのレビューファイルを参照（過去の改善点を確認）

## レビューの実施タイミング

以下のような場合にレビューを実施します：

1. **規約の更新時**: `AGENTS.md`・`.agents/実行ルール.md`・`.agents/サブエージェント抜かし防止.md` 等を更新した際
2. **テンプレートの更新時**: `.workflow/templates/` のテンプレートファイルを更新した際
3. **ワークフローの改善時**: ワークフロー全体を見直す際
4. **定期的な見直し**: 規約やテンプレートの有効性を確認する際
