# CI テンプレート（pnpm 順序・backend 環境変数）修正 レビュー

**レビュー実施日時**: 2026 年 3 月 3 日 02:49:43  
**レビュー対象**: `.workflow/templates/github/workflows/ci-check.yml` および `.workflow/templates/github/README.md` の更新  
**レビュー担当**: [`.review/README.md`](./README.md) に従い実施（テンプレート更新時のレビュー）

---

## 背景

採用先リポジトリ（d-pops-voice-check-poc）で CI 実行時に以下が発生したため、同様の事象を防ぐよう汎用テンプレートを修正した。

1. **frontend-check**: `actions/setup-node@v4` の `cache: 'pnpm'` が、pnpm 未インストールの状態で pnpm を実行しようとして失敗（「Unable to locate executable file: pnpm」）。
2. **backend-check**: テスト実行時に Pydantic Settings の必須環境変数（`minio_secret_key` / `secret_key` / `internal_api_key`）が未設定で ValidationError。

---

## 変更内容

### ci-check.yml

| 箇所 | 変更 |
|------|------|
| ヘッダーコメント | frontend は「pnpm を setup-node より先に Install pnpm を実行すること」と理由を追記。backend は「テストで必須の環境変数がある場合は job の env に設定する」を追記。 |
| frontend-check | 「Install pnpm」（`pnpm/action-setup@v4`）を「Set up Node」（`actions/setup-node@v4`）**より前**に移動。 |
| backend-check | 必須環境変数用の `env` 例をコメントで追加（MINIO_SECRET_KEY / SECRET_KEY / INTERNAL_API_KEY）。 |

### README.md

- 「CI と監査スクリプト」に**採用時の注意**を 2 項目追加：
  - (1) フロントでは pnpm を setup-node より先にセットアップすること。
  - (2) バックエンドのテストで必須の環境変数がある場合は、`backend-check` ジョブに `env` を追加すること。
