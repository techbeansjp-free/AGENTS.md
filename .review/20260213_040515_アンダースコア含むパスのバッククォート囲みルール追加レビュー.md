## 変更内容の概要

### 追加された内容

1. **クイックリファレンス（4. 参照パス確認は必須）**
   - 「アンダースコアを含むパスはバッククォートで囲む」を追加
   - 理由: Markdown の `_` 強調解釈やフォーマット変換で `*` に変わってパスが壊れるのを防ぐため

2. **基本ルール「3. 参照パスの確認」**
   - 方針に「アンダースコアを含むパスはバッククォートで囲む」を追加（href は `_` のまま、リンクテキスト・本文表記は `` `...` `` で囲む）
   - 正しい例・間違った例を追加

3. **LLM エージェント向け実行ルール「4. 参照パスの確認」**
   - 守る項目にバッククォート囲みを追加
   - 禁止事項に「アンダースコアを含むパスを本文にバッククォートなしで書く」を追加

4. **AI 自己チェックリスト**
   - 「アンダースコアを含むパスをリンクテキスト・本文で `` `...` `` で囲んでいるか」のチェック項目を追加

### 変更の目的

- 採用プロジェクトで `.workflow/YYYYMMDD_HHMMSS_issue名/90_issues` 等のパスを Markdown に書いた際、フォーマッタやレンダラが `_` を強調（イタリック）と解釈し、`*` に変換して参照が壊れる事象を防ぐ
- ドキュメントルールに従う AI が、同様のルールを遵守してパス表記を行うようにする
