# ディレクトリ構造方針

ディレクトリ構造は **責務単位で整理する。**

---

## 基本構造

```
module
 └ usecase
     └ event
```

---

## module

業務ドメイン。

例

- auth
- orders
- jobs
- notifications

---

## usecase

システムの操作。

例

- create_user
- upload_audio
- retry_job

---

## event

発生した事実。

例

- UserCreated
- AudioUploaded
- JobCompleted

---

## shared の扱い

shared は最小限にする。

以下を shared に置く。

- 共通型
- 共通エラー
- 共通ユーティリティ

以下は shared に置かない。

- ビジネスロジック
- ドメインルール
