## 真因（Major）

`src/domain/finalize.ts`。

```ts
trackedChanges:
  input.trackedChanges === undefined
    ? typeof input.clean === "boolean" ? !input.clean : undefined
    : input.trackedChanges,
```

**`trackedChanges`が与えられていれば`clean`は完全に無視される。**

`trackedChanges: false`（変更なし）と`clean: false`（汚れている）が同時に来ると、**矛盾を無視して削除可の側**を採る。

PR #900で`Array.isArray(x) ? x : []`型のfail-openを9箇所是正したが、**「矛盾を無視する」という別形態**が残っていた。

### 敵対観点の残論点

**矛盾検査は与えられた観測の組にしか働かない。** 呼び出し側が片方しか渡さなければ検査は起きない。CLIが両方を渡す実装であることに依存しており、**将来CLIが片方を省略するように変わると検査が無効化される。** 検査の存在をtestで固定しているが、呼び出し側の変更は検出できない。

**#900をレビュー完了前にmergeしたことで、本是正が別PRになった。** 本来は1つのPRで完結すべきであった。mainには短期間、矛盾を無視する実装が存在した。
