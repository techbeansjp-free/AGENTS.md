## 3. 肯定的評価

- **自分の案が不健全であることを諮問で示され、採らなかった。** 40桁hexの一律伏字は`audit:check`が検証しないSHA改変を洗浄する。**Issueへ棄却理由を明記した。**
- **緩和範囲を「独立導出でき独立検証できる2欄」へ限定した。** citation・Evidence・例示中のOIDは比較対象に残る。
- **caller申告を信用していない。** 宣言`H_impl`を`H_impl..H_final`がartifact 1件であることで検証する。
- **拒否理由が条件を区別する。** 変異8件が条件ごとに別のscenarioへ殺される。**理由を1種類にしていたときは5件生存していた。**
- **正規経路が閉じたままにならないよう`review round`側も直した。** 再固定だけ直しても次の前進修正で塞がる。

## 4. 敵対的評価

- **緩和した2欄の正しさは`audit:check`に依存する。** 本変更が検証するのは「宣言`H_impl`が構造と一致すること」と「宣言`比較基点`が再固定の基点と一致すること」までである。**`比較基点`が「取り込み先branchの最新commit」であることは検証していない。** その性質は`audit:check`が持つ。**本判定単体では、両方の値が揃って偽である入力を排除できない。**
- **artifactが1件でない差分では二層へ落ちない。** `artifact-not-unique`で拒否する。**その形が正当な運用として現れるかを測っていない。** 現れるなら正規経路はまた閉じる。
- **本判定は候補側にあり敵対耐性を持たない。** `src/`は保護対象ではなく同一PRで緩和できる。
- **既存20 scenarioは二層の経路を通らない。** artifactを持たないfixtureのため完全一致で判定される。**回帰の担保は「変えていない」ことの確認であり、二層経路の回帰ではない。**
- **`review round`の実効HEAD対応にscenarioが無い。** 既存45件が通ることは確認したが、**「再固定成立後に前進修正でroundを開ける」ことを直接観測するscenarioを足していない。**
