## 真因と経緯

v0.2系では`.github/workflows/agent-skill-chain-release.yml`がmainへのpushを契機に自動releaseしていた。同fileはIssue #824のv0.3刷新（PR #825、commit `320213fd`）で他の旧`.github`資産と一括削除され、以後自動releaseの経路が存在しない。最新Releaseは`v0.2.138`（2026-08-22）のままだった。

Issue #826で新しいrelease workflowを追加したが、同Issueの受け入れ条件「本実行は明示的な入力と最小権限を要求し、通常の`main` pushでは開始しない」に従い`workflow_dispatch`専用として実装した。**この受け入れ条件はrepository ownerの実際の意図と異なっていた。**

repository ownerが2026-08-25に確定した事項は次のとおりである。

- mainへのmergeをreleaseとみなす。
- tagとGitHub Releaseは自動で作成されるべきである。
- npm公開は行わない。

本変更はこの確定事項へ実装を合わせるものであり、課題826の追跡文書も同時に改訂する。

## 再帰トリガ防止の3機構

reviewerが実workflowで次を確認した。単一の機構に依存していない。

1. **skip ciガード**: `validate` jobの`if`が`github.event_name != 'push' || !contains(github.event.head_commit.message, '[skip ci]')`。version bump commitとPR titleの双方へ`[skip ci]`を含める。
2. **concurrency**: `group: main-mutator`、`cancel-in-progress: false`。同時実行を直列化する。
3. **存在チェック**: tag作成前に`git ls-remote --tags`で同名tagの不在を確認し、Release作成前に`gh release view`で確認する。いずれも冪等。

さらに`paths`限定により、`docs/`・`memo/`・`test/`・`.github/`だけの変更ではworkflow自体が起動しない。

## npm公開が自動経路から呼ばれない根拠

`npm_publish` jobの`if`は次の連言である。

```
github.event_name == 'workflow_dispatch' &&
inputs.publish_npm == true &&
needs.validate.outputs.state == 'ready' &&
needs.validate.outputs.npm_enabled == 'true' &&
needs.tag.outputs.state == 'succeeded' &&
needs.github_release.outputs.state == 'succeeded'
```

第1項が`workflow_dispatch`を要求するため、`push`イベントでは**評価の時点で偽**になる。第2項の`publish_npm`は既定`false`である。`SCN-INT-AUTORELEASE-002`が、自動npm公開を含むworkflowを反例として拒否することを固定する。

### 敵対観点の残論点

version bump PRのadmin mergeは`secrets.RELEASE_MAIN_PAT`を使う。このtokenがrepository権限を持つため、workflowの改変が権限昇格につながる経路は理論上残る。ただし`.github/workflows/release.yml`の変更はPRとCIを経由し、`ASC-DOGFOOD-CI-PERMISSION-001`と`ASC-DOGFOOD-CI-TRIGGER-001`のrule台帳対象でもある。tokenをworkflow外へ出力するstepは`validateReleaseWorkflow`の秘密値出力検査が拒否する。

bump PRが自動mergeされる経路は、Issue #832で追加した`ASC-DOGFOOD-OWNERSHIP-PR-001`のowner根拠要求とは別系統である。releaseのversion bumpは機械的な1行変更であり、人のreviewを要する変更ではないという判断に基づく。この判断が誤りであった場合はbump PRを人手merge required へ変更できる。
