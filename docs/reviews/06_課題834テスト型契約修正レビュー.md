## H-TEST-TYPING-001解決証拠

- `WorkflowWorld extends World<WorkflowParameters>`とし、Before、After、step callbackへ同じWorld型を伝播させた。
- 6つのstep fileが、それぞれ操作別のWorld interfaceと`stepDefinitions<...>()`を使用する。
- `eslint.config.mjs`の型認識rule対象を`{src,bin,scripts,test}/**/*.ts`へ拡張した。
- `scripts/check_project_quality.ts`がtestを含むESLint scope、Cucumber stepの直接import禁止、全step fileの型付きWorld拘束を検証する。
- SCN-UNIT-QUALITY-006が直接importによる自己緩和を反例として拒否する。
- `npm run prepack`: 合格。
- 全BDDを通常testとconformance証拠生成で各1回実行し、いずれも273 scenarios / 1548 steps合格。
- lint、Prettier、TypeScript strict、source quality、build、文書、Gherkin、trace、architecture、conformance、audit、package内容: 合格。
