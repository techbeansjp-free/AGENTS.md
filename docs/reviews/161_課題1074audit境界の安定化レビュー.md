## 4. 敵対的評価

- **予算の消費は完全には消えない。** `pr create`が`latestCandidateHeadSha === PR head`を要求する以上、**最後のroundより後のcommit 1本でroundは1消費される。** 消えるのは「`H_impl`の追随が新たなcommitを呼ぶ」連鎖だけで、**artifactの内容訂正そのものは依然としてラウンドを使う。** #980のround 2（テスト件数の訂正）は本変更後も発生する。
- **歯止めが停止条件を覆っている。** R4が観測不能になった（DISC-005）。**多重防御と言えば聞こえはよいが、覆われた条件は変異で守られていない。** 将来この歯止めを外すと、R4が守っていたはずの性質が静かに失われる。
- **遡りは`H_impl..current`を広げる操作であり、本質的に緩める方向である。** 歯止めで塞いだのは実測した1経路（release bumpの吸収）であり、**他に同種の吸収経路が無いことは示していない。**
- **本検査は候補側にあり敵対耐性を持たない。** `scripts/check_file_audit.ts`は保護対象ではなく同一PRで緩和できる。
- **既存artifactの移行を測っていない。** `audit:check`は現在のHEADから導出するため過去を再検査しないと述べたが、**その性質をscenarioで固定していない。**
