## レビュー中に検出した問題と是正

| 問題 | 真因 | 是正 |
|---|---|---|
| `SCN-INT-CHOICE-001`が弱化として拒否されて失敗 | 実repositoryのproject choiceを読んだうえで`modelMapping`全体を、新fieldを持たない旧fixtureで置換していた。適用後は正しく弱化と判定される | gate側を変えず、trusted側の`modelMapping`をlegacy文字列へ差し替えてからcandidateを作る形へfixtureを是正した |
| `minimumTierByRisk`が全risk classで`critical`となり誤blockを生む | 初版はすべて`critical`を宣言していた。`path` riskはread-only列挙や定型整形でも発生するため、`critical` modelを常に要求することになる | `path`を`routine`へ調整した。effective tierはpackage計算値との`max`で決まるため弱化にならず、`path`＋通常実装は`standard`、`path`＋architecture/security scopeは`advanced`へ解決する |

是正後の解決例は次のとおりで、4 tierすべてに使用余地がある。

| 入力 | 解決tier |
|---|---|
| `path` ＋ read-only列挙・定型整形 | `routine` |
| `path` ＋ 通常実装 | `standard` |
| `path` ＋ architecture・security scope | `advanced` |
| `secret` / `authority` / `irreversible` / `identity` / `artifact` | `critical` |
