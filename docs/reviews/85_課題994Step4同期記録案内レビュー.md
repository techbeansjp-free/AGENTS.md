**反例の内容。** 2種類の入力を同じscenarioで検査する。

1. `--staging-path`だけを渡す → 拒否理由が`fullのStep 4では同期記録を更新せず、workflow record --step=4`を含む
2. 配置違反のstaging pathと`--checkpoint=4`を渡す → 拒否理由が`同期記録は.agent-skill-chain/tmp/issues/直下のstagingだけに書き込めます`を含む

**この反例が示すのは「期待した拒否理由が返る」ことである。** GitHub adapterの呼び出し回数は観測していないため、「GitHubへ到達しない」ことを直接は証明していない。ただし対象repositoryは実在せず、同期が先に走れば`gh`側のerror messageになるため、**順序が戻ればこの反例は落ちる。** 実際に変異で確認した（下記）。

**変異試験。** 事前検査の呼び出しを`github("issue.sync", …)`の後ろへ戻すと、SCN-UNIT-CLIUSAGE-014が失敗する（`1 scenario (1 failed)`）。
