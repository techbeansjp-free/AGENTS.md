# 機能拡張conformance contract

この12命題は、#830〜#833を含む以後の機能拡張が守る薄い基盤である。主経路は`要求 → domain境界・不変条件 → 実行可能AC → failing test → 最小実装 → risk比例検証 → 独立review → PR`であり、contractはこの経路を支援する。

| ID | 不変条件 | Source of truth | Enforcement point | Counterexample Gherkin | Evidence | Rollback |
|---|---|---|---|---|---|---|
| I1 | safety境界以外をdenyせず安全な次行動を返す | package conformance contract | rule validation・operation enforcement | SCN-UNIT-RISK-003 | risk、強度、diagnostic | ruleをstaged/assistへ戻す |
| I2 | package contract(A)、project choice(B)、this repo rules(C)、implementation evidence(D)を分離しconsumer-ownedを保持する | ownership contractとtrusted project policy | ownership local assist・PR require・全変更path監査・artifact deny | SCN-UNIT-RISK-016、SCN-UNIT-PACKAGE-011 | owner、targetLayer、分類根拠、Git差分path集合 | 正しい所有layerへ移動する |
| I3 | requirementからreview/spec evidenceまで追跡する | durable issueとspec trace | trace validation・PR evidence | SCN-UNIT-TRACE-001 | requirement/SCN/test/review/spec ID | 不足linkを補いPRを保留する |
| I4 | candidate自己緩和とimplementer自己承認を禁止し能力と権限を分離する | trusted default policy | policy comparison・independent review・merge/finalize再認可 | SCN-UNIT-RISK-010、SCN-INT-MERGE-009、SCN-INT-FINALIZE-005 | trusted/candidate hash、review actor、review ID、trusted finalize policy | trusted条件を復元する |
| I5 | repo/remote/base/worktree/path/Git内部/unrelated assetを隔離する | trusted identity evidence | path・worktree・delivery境界 | SCN-INT-WORKTREE-003、005 | exact identity、SHA、canonical path | 書き込み前状態を保持する |
| I6 | 証拠をexact SHA/policy/tool/scope/successへ拘束しfailed/staleを再利用せずfinal fullを維持する | validation evidence contract | validation planner・final gate | SCN-UNIT-RISK-012、023 | fingerprint、passed、scope、tool | stale・failed証拠を破棄して再検証する |
| I7 | preview、直前再確認、read-after-writeをjournal化しcrash後も回復可能にする | migration manifest | migration apply/rollback/retry/recover | SCN-INT-RISK-005、013、025〜026 | target、durable before content、before/after hash、revision、必須durable journal | before contentから全targetを復旧しhashでintegrityを検証する |
| I8 | project state/evidence/secretを実artifactへ混入させない | artifact manifest | 実pack boundary | SCN-INT-RISK-008 | pack file list、allowlist | 汚染artifactを公開しない |
| I9 | offlineでもlocal安全作業を継続しexternal必須だけpendingにする | gate dependency declaration | offline planner | SCN-UNIT-RISK-006 | local ready・external pending一覧 | online planへ戻し保留だけ再試行する |
| I10 | 単責務・明示I/O・合成可能・最小共有状態・非循環graphを守り旧harness/hidden stateへ依存しない | package architecture | generic dependency graph validator・package boundary | SCN-UNIT-TRACE-006〜007、SCN-UNIT-PACKAGE-003 | topological order・cycle反例 | 循環edgeと新規依存を除去する |
| I11 | rule/根拠/scope/remediation/authority/rollback/metricsを秘密なしで記録する | diagnostic contract | serializer・metrics validation | SCN-UNIT-RISK-011 | redacted structured output | secretを失効し安全な記録へ置換する |
| I12 | language/runner/layers/test file禁止suffix/naming/package manager/runtime/CI/model mapping/releaseはproject policyで選択する | trusted project choices | effective policy resolution | SCN-UNIT-RISK-014 | 選択値とowner evidence | package floorを保持してproject choiceを戻す |

Contractの機械正本は`.agent-skill-chain/policy/conformance.json`、構造契約は`.agent-skill-chain/schemas/conformance-contract.schema.json`である。具体的なproject choicesとrepository ruleは`.agent-skill-chain/project-policy.json`、実装・テスト証拠は`docs/specs/`と隔離fixtureへ置く。静的keywordや巨大な単一gateではなく、単責務のenforcement pointを合成する。
