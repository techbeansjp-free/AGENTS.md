## Ownershipとproject choices

汎用package contract、projectが選択する開発方式、このrepositoryの規約、仕様、実装・test・review証拠をownerと`package / project / spec / evidence` targetLayerで分離する。localは誤配置をassistし、PRはowner/evidenceをrequireし、実artifactへのproject/spec/evidence/secret混入だけをdenyする。表示言語、runner、Gherkin構造keyword方言、test layer数と名称、test file禁止suffix、命名、package manager、runtime、CI、model mapping、release方式は`.agent-skill-chain/project/choices/`を正本とし、汎用defaultやtemplateへ具体値を埋め込まない。`.agent-skill-chain/project-policy.json`はfragment inventoryとauthority coreだけを持つ。

このrepositoryはNode CLIであるため、実装言語はTypeScript、型解析はstrict、禁止型は`any`とする。Pythonとshellは`not-applicable`とし、必要な検査もTypeScriptへ統合する。具体的なESLint、Prettier、TypeScript、tsxの選択とコマンドはproject choiceが所有し、汎用文書は製品名を固定しない。Privacy/SecurityとObservabilityはCLIでも`applicable`、UI/UXとDesign/Layout TokenはUIを持たない現状では`not-applicable`とし、適用判断と証拠をproject choiceに保持する。

`deny`はsecret、path、authority、irreversible、identity、artifact riskに限定する。unknown field/versionは黙殺せず、project policy `v0.3.0`から`v0.3.1`へのstaged migrationとrollbackを診断する。速度向上を理由にsecurity、受け入れ条件、独立review、最終full testを省略しない。BDDの実行可能acceptanceとstable SCN/trace IDは汎用core、層数・層名・runner・file禁止patternはproject choice/bindingである。generic runtimeは選択された層だけを検証し、templateは選択層を注入するhookだけを提供する。
