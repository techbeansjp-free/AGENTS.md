# 移行・廃止方針

v0.3は、旧harnessを意図的に削除した`renewal_v0.3.0`を基点に独立実装する。旧`.agents/`、`.workflow/`、hooks、commands、enforcementを無条件に復元せず、doctorで残存を報告するだけとする。

`init`は新規導入、`upgrade`はpackage所有資産だけの更新、`uninstall`はmanaged hashが一致する資産だけの削除を担う。利用側所有の仕様、project policy、変更済み品質文書、一時stagingを保持する。

ロールバックはv0.3実装コミットを戻し、旧harness削除済みの基点へ戻す。package公開、release、既存利用者への自動移行は今回の範囲外である。
