# API・外部インターフェース一覧

| 契約ID | 種別 | 相手 | 目的 | 版 | 方向 | 個別仕様 |
|---|---|---|---|---|---|---|
| CLI-001 | CLI | 利用者・CI | lifecycle、Issue、workflow、policy、routing、worktree、delivery操作 | v0.3 | 受信・送信 | `01_コマンド・GitHub契約.md` |
| GH-001 | HTTPS API | GitHub | Issue、PR、review、check、branch protection、merge、Releaseの観測と許可済み更新 | GitHub API現行版 | 受信・送信 | `01_コマンド・GitHub契約.md` |
| NPM-001 | CLI・registry | npm | lockfileに基づく依存取得、pack内容検証、明示された手動公開 | npm CLI現行互換版 | 受信・送信 | `01_コマンド・GitHub契約.md` |
| PROC-001 | 子process | Git、gh、provider CLI | 引数配列によるlocal Git操作とread-only provider観測 | 実行時解決 | 受信・送信 | `01_コマンド・GitHub契約.md` |

## 共通既定値

- 外部入力は認証済みでも信頼せず、形式、意味、権限を検証する。
- 契約には版、互換方針、timeout、再試行、冪等性、error形式を含める。
- 外部状態の更新前に対象の完全な同一性を再検証し、更新後に再読取する。
