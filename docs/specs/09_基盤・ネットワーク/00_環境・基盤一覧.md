# 環境・基盤一覧

常設server、独自network、公開portは該当なしである。実行環境は利用者localまたはGitHub Actionsで、外部接続はGitHub APIとnpm registryに限定する。

| 環境ID | 用途 | 区画 | 計算資源 | データ | 外部接続 | 所有者 |
|---|---|---|---|---|---|---|
| ENV-001 | 開発・local検証 | 利用者worktree | Node.js 20以上 | repository、隔離fixture | 必要時だけGitHub API・npm registry | 利用project owner |
| ENV-002 | PR品質検証 | GitHub Actions runner | workflow指定Node.js | read-only checkout、短期artifact | npm registry、read-only GitHub API | repository owner・GitHub |
| ENV-003 | release | 保護されたGitHub Actions job | workflow指定Node.js | pack、tag、Release、手動時npm package | GitHub API、npm registry | repository maintainer・registry owner |

## 共通既定値

- 開発・検証・releaseの資格情報、data、write権限を分離する。
- 実IP、秘密、個人情報は仕様と公開図へ記載しない。
- 通信の送信元、宛先、方向、認証、用途は`01_実行境界.md`で管理する。
