# システム概要

`agent-skill-chain`は、人とAIがIssue駆動で開発するときに、計画、仕様、隔離実装、テスト、レビュー、PR、条件付きマージを安全側に統制するNode.js CLIパッケージである。

## 利用者と目的

| 利用者 | 目的 | 権限境界 |
|---|---|---|
| 開発者 | 日本語の仕様とGherkinを基に実装・検証する | 明示許可されたリポジトリと操作だけを実行する |
| AIエージェント | ステップ0〜11を再現可能に進める | 不明時は停止し、PR自身の統制を信頼しない |
| レビュアー | 肯定・敵対両面でriskを裁定する | 必須要件変更とrisk受容は人間権限とする |
| プロジェクト所有者 | merge modeと操作権限を既定branchで管理する | merge、close、削除、releaseを分離する |

## 対象範囲

Issue一時ステージング、quick/full判定、仕様書初期生成、GitHub同期、worktree、レビュー、PR、merge代行、導入・更新・診断・削除を対象にする。導入時はClaude CodeとCodexのrepository skill探索pathへ共通のhost skill登録アダプターを配置し、Step 0〜11の正本へ誘導する。ADR subsystem、release、package公開、Issue close、branch/worktree削除の自動連鎖は対象外である。
