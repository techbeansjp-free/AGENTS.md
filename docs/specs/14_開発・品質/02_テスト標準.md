# テスト標準

単体、結合、E2Eの全テストを`test/features/`配下へ日本語の説明で起票し、各Scenarioへ一意のSCN IDを付ける。構造keywordの方言はproject choiceの`gherkinDialect`を正本とし、このrepositoryは`en`を選ぶ。TypeScriptのstep定義は実行実装であり、起票の正本ではない。step/supportもstrict型検査と`any`禁止の対象に含める。

BDDは要求、具体例、受け入れ条件を実装前に確定するために使う。TDDは標準必須processにせず、変更種別、risk、影響境界、要求、AC、影響分析から必要なVerification Setを選ぶ。Bug Fixの再現、critical logicなどtest-firstが強いEvidenceを生む場合には採用する。新機能は実装とtestを同じimplementation phaseで効率的に生成してよい。Refactorはbaseline PASSとregression PASSを主Evidenceにする。

正常、失敗、境界、悪用、ロールバックに加え、パス走査、Unicode、原子性、リモート誤認、秘密情報、TOCTOUを該当境界で確認する。実workspace、実remote、他worktreeをテストから変更・削除しない。**fixtureは実時計と実repositoryの可変状態へ依存しない。** 時刻は`test/support/fixture-instant.ts`の基準時刻からの相対値で表し、絶対時刻をhardcodeしない。`package.json`、`package-lock.json`、`.agent-skill-chain/project/`はfixtureが自作するか環境変数で注入する。dogfoodingとして実値が必要な場合だけ理由を添えて宣言する。

CIはpull requestだけで発火し、lint、ソース整形、strict型検査、source quality、日本語文書、Gherkin形式、build、配布物、単体、結合、E2Eを検証する。ソース整形と日本語文書・Gherkinの形式は別のgateであり、一方の合格をもう一方の証拠に代用しない。

Risk比例policyはunitでrule強度、diagnostic、自己緩和、override、offline、dedupe、metricsを検証し、integrationでmigrationとpackage境界、E2Eで通常拡張、安全拒否、rollback retryをdogfoodする。Targeted実行の重複抑止後もCIの最終full suiteは維持し、候補差分が記録したfileを成功証拠の信頼境界にしない。

外部JSONは型不正・未知fieldを持つmanifest/stateを副作用前に拒否し、readerからdomain型へのgeneric castが再導入されていないことをunitで検証する。品質契約migrationは、base事前登録済みproposalとのexact match成功と、同一PRでの登録・利用による自己承認拒否を対にして検証する。

成果物統制語彙は、正本に必要語と正方向があること、要求・要件・設計・計画・レビュー・システム仕様templateが正本を参照すること、関連Step skillが開始前に読むことをunitで検証する。単なる語句出現ではなく、少なくとも1語を欠落させた反例がbuild gateで拒否されることを証明する。

ドメイン用語台帳は、要求の候補差分、要件の確定差分、実装後の耐久台帳で責務別の必須列を検証する。関連Step skillの開始前読取と、用語ID・business rule・コンテキスト・例と反例・根拠・owner・状態・適用版・置換先の欠落を拒否する反例を持つ。

host skill登録アダプターは、unitでfrontmatter・正本link・package収録、integrationでinstall・同一file採用・異なるfile保持・管理中更新・限定削除・doctor・legacy判定・symlink境界外write拒否、E2Eで公開CLIの導入から削除までを一時directory内だけで検証する。

Semantic GraphはBDDでREQ-GRの受け入れ例を固定し、unitでschema・canonical hash・drift・bounded BFS・Kahn・iterative Tarjan・Dijkstra、integrationでGit projector・GraphQLite round-trip・原子generation・worktree isolation、E2Eで`graph install / rebuild / status / impact / path / order`を検証する。順序入替のproperty test、小規模referenceとのdifferential test、digest不一致・query injection・deep cycle・TOCTOU・budget超過の反例を持つ。Node 20の公式配布binaryで非Graph CLIがGraphQLite adapterを読み込まず成功することと、Node 22.13未満のGraph commandが副作用前に拒否されることを検証する。AI推論は候補作成に使えるがGate Evidenceにはしない。

完了観測は実worktreeまたは実日数に依存せず、OSの一時directory内の隔離疑似projectでFull・Quick・PoCを別scenarioとして、固定instant・注入provider response・固定extension fixtureにより通常・境界・失敗・復旧を1回のsuiteで再現する。
