# テスト標準

単体、結合、E2Eの全テストを`test/features/`配下の日本語Gherkinで起票し、各Scenarioへ一意のSCN IDを付ける。JavaScriptのstep定義は実行実装であり、起票の正本ではない。

期待する失敗を先に確認してから最小実装を行う。正常、失敗、境界、悪用、ロールバックに加え、パス走査、Unicode、原子性、リモート誤認、秘密情報、TOCTOUを該当境界で確認する。実workspace、実remote、他worktreeをテストから変更・削除しない。

CIはpull requestだけで発火し、日本語文書、Gherkin形式、型、build、配布物、単体、結合、E2Eを検証する。
