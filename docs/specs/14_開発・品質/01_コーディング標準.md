# コーディング標準

Node.js 20以上のESMと、厳格なJSDoc型検査を使う。ドメイン関数は入力・出力を明示し、テストではアダプターを注入する。NFC正規化を行い、制御文字とパストラバーサルを拒否し、複数ファイル状態を原子的に公開し、診断から秘密情報を伏字化し、信頼できない値をシェル文字列へ展開しない。

`npm run docs:format`、`npm run test:format`、`npm run typecheck`、`npm run test:unit`、`npm run test:integration`、`npm run test:e2e`、`npm test`、`npm run package:check`を実行する。テストはOSの一時ディレクトリまたは模擬コールバックだけを使い、実GitHubリモートを呼ばない。安全性に関わる変更には正常系以上の失敗系を用意する。シェルを変更した場合だけShellCheckを行う。v0.3にはシェル実装がない。

npm配布物には、リポジトリ開発専用の`test/`、`.github/`、`scripts/`、`docs/specs/`、Cucumber・TypeScript設定、`node_modules/`、`memo/`を含めない。
