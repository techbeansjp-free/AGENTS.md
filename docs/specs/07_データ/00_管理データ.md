# 管理データ

| データ | 正本 | 所有者 | 保持・更新 |
|---|---|---|---|
| Issue本文 | GitHub Issue #824 | リポジトリ所有者 | GitHub上で耐久化し、同期後に再読取する |
| Issue作成前staging | `.agent-skill-chain/tmp/issues/` | 利用側 | Git管理外。正本ではなく同期前だけ保持する |
| project policy | 既定branchの`.agent-skill-chain/project-policy.json` | プロジェクト所有者 | 候補PR側の変更をmerge判断へ使用しない |
| system specification | `docs/specs/` | 利用側 | 初期生成後はupgradeで上書きしない |
| review・test証拠 | HEAD SHAに結び付いたJSONとPR/Issue記録 | 実行主体 | PR判断時にSHA一致を検証する |
| managed asset記録 | `.agent-skill-chain/managed-assets.json` | lifecycle | hash一致したpackage所有物だけ削除対象にする |

複数ファイルのstagingと仕様初期生成は、一時隣接ディレクトリへ完成させてから原子的に公開する。

Policy migration stateはplan ID、from/to version、適用前snapshot、candidate、compatibility、historyを持つ。Override監査はrule ID、Issue、scope、actor、理由、期限、SHAだけを保持し、秘密値を含めない。開発計測はgateWaitMs、duplicate、falseBlock、override、rollback、missの集計値を扱う。

`.agent-skill-chain/project-policy.json`、`.agent-skill-chain/tmp/`、role log、開発計測、test fixture、秘密情報は利用側・開発用データでありnpm packageへ含めない。
