# ID命名規則と管理

本ドキュメントは、本仕様書群で使用する**全 ID の唯一の台帳**である。新しい ID を追加する際は、必ず本ドキュメントの該当一覧表に登録してから使用すること。未登録の ID の使用は、監査・レビュー（[`.agent-skill-chain/source/DOCS_RULES.md` §継続追随ゲート](../../.agent-skill-chain/source/DOCS_RULES.md)）で検出する。

## ID命名規則一覧

| プレフィックス | 意味 | 使用箇所 | 本リポでの採番状況 |
| -------------- | ---- | -------- | ------------------ |
| `F` | Functional（機能単位） | [04 機能設計](../04_機能設計/README.md) | 採番あり（F01〜F05） |
| `T` | Table（テーブル） | [03 データ設計](../03_データ設計/README.md) | 採番あり（T01） |
| `G` | GUI（画面） | [02 画面設計](../02_画面設計/README.md) | 該当なし（非 GUI） |
| `API` | API 仕様 | — | 該当なし（新規 API 定義なし） |
| `S` | Sequence（シーケンス図） | — | 該当なし |

## ID管理のルール

1. **新規 ID 追加時**: 本ドキュメントの該当一覧表を更新してから使用する。
2. **ID 定義時**: 本台帳を参照し、重複・不整合がないことを確認する。
3. **ID 変更・削除時**: 本台帳と該当する全ドキュメントを同時に更新する。
