# 要求定義書: ゲート無効化 env トグルの具体的な設定方法を README に明記

**作成日**: 2026年07月15日
**最終更新**: 2026年07月15日

## 1. 目的・背景

### 1.1 目的（必須）

各ゲート無効化トグルの具体的な設定方法（shell/CI）を enforcement/README.md に明記する。

### 1.2 背景

- **現状の課題**:
  - `.agent-skill-chain/source/enforcement/README.md` は `GITHUB_ISSUE_GATE_ENABLED`・`BRANCH_LINK_GATE_ENABLED`・`PR_LINK_GATE_ENABLED`・`MODEL_TIER_GATE_ENABLED`（および対応する `*_GATE_EFFECTIVE_FROM`）を「設定する」とだけ記載し、配布先（フレームワーク利用者）がどこで・どうやって設定するか（シェル export か、CI の env/secrets か）を書いていない。
  - `.agent-skill-chain/project/自己拡張ワークフロー.md §8` にも「具体の設定手段は消費者環境に委ねる」とあるのみで、汎用的な設定例が存在しない。
- **必要性**:
  - 利用者がゲートを無効化したい場合に迷わず設定できるようにする。

### 1.3 期待される効果（必須: 1 件以上）

- **効果 1**: README の各ゲートトグル説明に具体的な設定方法（シェル環境変数・CI の env/Secrets and variables）が明記され、利用者が迷わず設定できる。

## 2. 機能要件

### 2.1 既存機能の維持

既存のゲート判定ロジック（audit.sh 側の実装）は変更しない。ドキュメント追記のみ。

### 2.2 新規機能要件

`enforcement/README.md` の「ゲート共通の前提（SKIP・grandfather・env トグル）」節に、env トグルの具体的な設定方法（シェル export・CI ワークフローの env ブロック・リポジトリ/Organization Settings の Variables）を追記する。

## 5. 除外要件

- 実装ロジック（audit.sh 等）の変更は行わない。
- `.agent-skill-chain/project/自己拡張ワークフロー.md §8` の「具体の設定手段は消費者環境に委ねる」という消費者側の判断尊重の記述自体は変更しない（役割分担: project 側は判断尊重、README 側は汎用的な設定方法の例を追加）。

## 6. 成功基準（必須: 1 件以上）

- README の各ゲートトグル説明（#34/#35/#36/#38 および共通前提ノート）に、シェル環境変数としての設定方法と CI（GitHub Actions）での設定方法の具体例が記載されていること。

## 9. 次のステップ

quick モードのため 01/02/03 は作成せず、design memo（変更理由・変更方針）と実装（README 追記）に進む。
