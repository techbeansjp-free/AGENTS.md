## 3. セルフレビューで発見し追加修正した項目（実装中に判明した波及）

02_設計 の対応方針を適用した結果、以下の**新たな不整合**を自己レビューで検出し、都度追加修正した（詳細は [04_review.md](./04_review.md) を参照）。

- **B-1 の波及**: 「各フェーズ完了時に verify-and-close」という記述は run_command.md・workflow/PHASES.md 以外に、**boot/CORE.md §メインとサブの役割**および **RULES.md §監査・書記**にも存在しており、02_設計時点で見落とされていた。両ファイルとも「実装完了後は verify-and-close、実装着手前は review-docs」に修正した。
- **AGENT_CONDUCT.md の見出しアンカー変更**: 第 3 部見出しの文言変更（A-9）により Markdown アンカーが変化し、skills/agent/run_command.md からの内部リンクが破損することを検出、リンクを追随修正した。
- **AGENT_CONDUCT.md §enforcement ゲートの自己無効化禁止**: `enforce off` を対象 env リストに追加した際、既存の「人間の明示指示があればエージェントが設定変更してよい」という一般例外条項と、A-3 の「`enforce off` の実行主体は人間のみ」という個別規定が字面上ぶつかる余地を検出。`enforce off` を一般例外から明示的に除外する文言を追加して解消した。
- **skills/agent/SKILL.md と run_command.md の両方に存在した「README.md または SKILL.md」表記**: 02_設計は SKILL.md(30) のみを対象としていたが、run_command.md 内の「command の実行のしかた」節にも同一表現があったため、同時に修正した。
