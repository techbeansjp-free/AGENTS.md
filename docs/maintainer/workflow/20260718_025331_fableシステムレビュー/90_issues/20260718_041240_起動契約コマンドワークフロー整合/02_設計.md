## 3. 「採用（要設計判断）」11件の詳細（トレードオフと推奨）

### 3.1 A-4: quick モード mode 信号の循環

- **案1（推奨）**: quick モードは「**frontmatter のみの最小 00_要求定義.md**」（`mode`/`branch`/`issue_id`/`github_issue` のみ、本文セクション・Mermaid マインドマップ省略可）を許容する。mode の機械可読正本（00 frontmatter）を維持したまま #35 branch ゲートを満たせる。
