## 方針の決め方

- **採用**: 指摘が正しく、対応する（対応の実施は本 issue の対象外。方針確定後、必要に応じて別途 GitHub Issue 化する）。
- **見送り**: 指摘が誤り・過剰・スコープ外と判断し、対応しない（理由を記載）。
- **要検討**: 実装・設計を確認したうえで、採用か見送りをあとで決める。

> 本ファイルの「方針」列は、独立検証エージェント群（7領域、opus）による全112件の再検証結果を反映して確定しています。**採用（要設計判断）** は、独立検証において指摘自体の妥当性は確認されたものの、対応方法が複数考えられ、いずれを取るかにトレードオフを伴う設計判断が必要と評価されたものです（＝対応する意思はあるが、実装着手前に設計フェーズで具体案を決定する必要がある指摘、という区別）。単なる保留の「要検討」とは異なります。
