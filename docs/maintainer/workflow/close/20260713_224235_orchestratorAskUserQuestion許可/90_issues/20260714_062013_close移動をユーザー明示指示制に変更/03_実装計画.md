## 5. テスト仕様（観点・BDD 相当）

ドキュメント改訂のため実行テストは無く、下記を検証観点とする（02 §4 テスト観点 T-1〜T-8 と対応）。

- **Given** GitHub 連携リポ（`git remote -v` に github.com）で **When** トップレベル issue が完了検知された **Then** 進行役は direct push で close 移動を確定せず、feature branch→PR→マージ経路を辿る（T-1・T-3 で文言確認）。
- **Given** GitHub 非連携リポで **When** トップレベル issue が完了検知された **Then** 進行役はユーザーの AskUserQuestion 肯定応答または明示コマンド句を受けるまで移動しない（T-3 で文言確認）。
- **Given** 本改訂 **When** `git diff` を確認する **Then** enforcement #33（README.md・audit.sh）と CORE.md 宣言に変更が無い（T-2・T-5・T-7 で確認）。
- **Given** 分岐 A/B いずれの手順 **When** 手順を読む **Then** リンク補正・検証が移動前に完結し、移動後 close/ 配下を読み取らない（T-6 で確認）。
