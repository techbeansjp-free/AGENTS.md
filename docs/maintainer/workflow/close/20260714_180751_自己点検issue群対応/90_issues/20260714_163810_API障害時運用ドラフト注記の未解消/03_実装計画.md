## 1. 実装概要

### 1.1 実装方針（必須）

`.agent-skill-chain/project/自己拡張ワークフロー.md` §5「API 一時障害・認証失効時の運用」の見出し・本文から、未確定を示す文言（「（要人間確認・ドラフト）」「暫定ドラフトである」「実運用に適用する前に、必ずユーザーの明示確認を得ること」「（ドラフト）」「（ドラフト値）」「上記はドラフトのため、確定後は本節を更新し、この確認要求の注記を除去すること」）を除去し、確定ルールとして記述し直す。リトライ 30 秒間隔・最大 3 回・エスカレーション運用の具体値自体は変更しない。

### 1.2 実装順序（必須: 1 件以上）

1. §5 の見出しを「### 5. API 一時障害・認証失効時の運用（確定）」に修正する。
2. §5 本文冒頭の引用ブロック（未確定事項・ユーザー確認要求）を削除する。
3. 各箇条書き末尾の「（ドラフト）」「（ドラフト値）」を削除する。
4. 末尾の「上記はドラフトのため、確定後は本節を更新し、この確認要求の注記を除去すること」の一文を削除する。
5. 修正後の§5 に具体値（30 秒間隔・最大 3 回・エスカレーション運用）が維持されていることを grep で確認する。
