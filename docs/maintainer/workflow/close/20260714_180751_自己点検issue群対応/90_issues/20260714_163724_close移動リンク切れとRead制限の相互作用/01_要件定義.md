# 要件定義書: close 移動リンク切れと Read 制限の相互作用

**プロジェクト名**: close 移動リンク切れと Read 制限の相互作用
**作成日**: 2026年07月14日
**最終更新**: 2026年07月14日

> **判断**: [00_要求定義.md](./00_要求定義.md) の成功基準どおり、(1) close/ の外側から close 済み issue を指す既存参照の補正を「恒久ルール」として `.agent-skill-chain/project/自己拡張ワークフロー.md` に追記し、(2) 既知の不達箇所 `.agent-skill-chain/project/MODEL_TIER_TABLE.md:34` を実際に修正することで対応する。既存の切れたリンク約 1,060 件の全件遡及修正は 00 §7.2 のとおりスコープ外。

## 1. 概要

close 移動時の「深度+1 補正手順」（`.agent-skill-chain/project/自己拡張ワークフロー.md` §close 移動時の相対リンク補正）は、移動する issue 自身のリンクのみを対象としており、close/ の**外側**にある正本文書（例: `.agent-skill-chain/project/MODEL_TIER_TABLE.md`）から close 済み issue を指す既存参照は補正対象外のまま切れて残る。さらに `.claude/settings.json` の close/ 配下 Read/Grep/Glob deny により、エージェントはこの種のリンク切れを（移動後は）検証・修復できない。本 issue では、今後の close 移動に適用する恒久ルールの追加と、既知の 1 件（MODEL_TIER_TABLE.md:34）の実修正を行う。

## 2. 機能要件

### 2.1 ユーザーストーリー

#### ストーリー 1: 保守者が close 移動時に外部参照の補正漏れを防げる

- **As a** issue を close/ へ移動する保守者（進行役）
- **I want to** 移動対象 issue を指す「close/ の外側からの参照」を移動前に洗い出し、深度補正する恒久ルールが明文化されている
- **So that** 移動後に deny 制約で検証不能になる前に、外部参照側のリンク切れを防止できる

**受け入れ基準**:

- `.agent-skill-chain/project/自己拡張ワークフロー.md` に、close/ の外側からの既存参照を洗い出す手順（`grep -rn` 等によるリポジトリ全体検索・分類・`close/` セグメント挿入・移動と同一コミット/PRでの実施）が明文化されている。
- 手順は既存の「移動前に完結させる」原則（§close 移動時の相対リンク補正）と矛盾しない。

#### ストーリー 2: 既知の不達箇所が解消される

- **As a** `.agent-skill-chain/project/MODEL_TIER_TABLE.md` を参照する利用者
- **I want to** §裁量禁止との整合 の close/ 参照リンクが実在パスに解決する
- **So that** リンク切れによる情報アクセス不能が解消する

**受け入れ基準**:

- `MODEL_TIER_TABLE.md:34` 付近のリンクが `docs/maintainer/workflow/close/20260712_120018_モデルティア選定方針のproject化/00_要求定義.md` を指し、`git ls-files` で当該パスが実在（追跡対象）であることを確認済み。

### 2.2 非機能要件

- **セキュリティ/制約**: `.claude/settings.json` の close/ 配下 deny 自体は変更しない（00 §5 除外要件）。リンク先実在確認は「パス一覧確認のみ」（`git ls-files`）で行い、close/ 配下ファイルの内容は読まない。
- **互換性**: 既存の「移動前に完結させる」補正手順を拡張する形とし、既存記載を壊さない。

## 3. 除外要件

- 既存の約 1,060 件のリンク切れ全件の遡及修正（00 §7.2 のとおりスコープ外）。
- `.claude/settings.json` 自体の変更（本リポでは非追跡のローカル設定であり、このタスクでは変更不能）。

## 4. 成功基準

- 00 §6 の成功基準（外部リンクの扱い方針の明文化、MODEL_TIER_TABLE.md:34 の対応方針決定）を満たす。
