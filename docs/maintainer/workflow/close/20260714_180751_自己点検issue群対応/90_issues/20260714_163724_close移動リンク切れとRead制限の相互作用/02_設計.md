## 1. 設計概要

### 1.1 設計方針

既存の「close 移動時の相対リンク補正」節（`.agent-skill-chain/project/自己拡張ワークフロー.md`）を拡張し、新規サブセクション「close/ の外側からの既存参照の補正（恒久ルール）」を追加する。加えて `MODEL_TIER_TABLE.md` の既知の切れたリンク 1 件を実修正する。新規スクリプト・新規ツールは作らない（既存の grep ベースの手順に倣う）。

本 issue は姉妹 issue（20260714_163717・20260714_164034）と同一ファイル（`自己拡張ワークフロー.md`）の近接箇所を対象とするため、3 issue分の追記は 1 回の編集で `## close/ 参照・deny 運用に関する方針（自己点検issue対応）` セクションとしてまとめて追加した（実装計画・レビューはそれぞれの issue 単位で記録する）。

### 1.2 設計原則

- **単一責務**: 適用する。恒久ルールの定義は自己拡張ワークフロー.md の close 移動節の直下に集約し、二重定義しない。
- **明確な境界**: 適用する。「移動する issue 自身のリンク」（既存手順）と「close/ の外側からの参照」（本 issue の新規手順）を明確に区別する。
