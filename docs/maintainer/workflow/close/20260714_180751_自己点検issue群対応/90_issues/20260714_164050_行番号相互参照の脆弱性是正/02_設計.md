## 2. アンカースラッグ化規則

GitHub の Markdown 見出しアンカー生成規則に準拠する（`check-relative-links.sh --check-anchors` と本 issue の変換の**共通正本**）:

1. 見出しテキストから先頭の `#` と前後空白を除去。
2. 英字は小文字化。
3. 空白を `-` に置換。
4. 英数字・`-`・`_`・Unicode 文字（日本語等）以外の記号を除去。
5. 日本語文字はそのまま保持（除去・変換しない）。

- 例: `### Constraints` → `#constraints`
- 例: `## テンプレートの正本` → `#テンプレートの正本`
- 例: `## レビュー成果物の配置ルール` → `#レビュー成果物の配置ルール`（既存 `run_command.md` が使用中の実績あり）

> リポジトリ既存の `#aiフレンドリー設計`・`#用語規約`・`#レビュー成果物の配置ルール` 等が同規則で解決している実績を確認済み。
