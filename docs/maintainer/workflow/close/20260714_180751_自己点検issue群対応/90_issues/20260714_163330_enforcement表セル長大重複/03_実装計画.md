## 5. リスク管理

### 5.1 実装リスク
- **リスク**: セル短縮の過程で固有の SKIP 条件・env トグル差分を落とす。
  - **対策**: 共通前提ノートへ移すのは「全行共通のパターン」のみ。ゲート固有値（発効日の既定値差・非交差関係）は行に残す。T3 のバリデーションで確認。
- **リスク**: 番号体系の付け替えで外部参照が切れる。
  - **対策**: 番号は不変（must-preserve）。行の追加のみで既存番号を動かさない。
