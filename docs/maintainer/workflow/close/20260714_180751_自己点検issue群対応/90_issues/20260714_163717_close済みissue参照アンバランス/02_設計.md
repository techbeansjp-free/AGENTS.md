## 1. 設計概要

### 1.1 設計方針

`.agent-skill-chain/project/自己拡張ワークフロー.md` の新設セクション `## close/ 参照・deny 運用に関する方針（自己点検issue対応）` 内に、サブセクション「正本文書における close/ 参照の位置づけ（経緯・ADR 参照の扱い）」を追加する（本 issue の主対応。同セクション内の他 2 サブセクションは姉妹 issue 20260714_163724・20260714_164034 が対応し、3 issue分は 1 回の編集でまとめて追加済み）。

### 1.2 設計原則

- **単一責務**: 適用する。方針の定義は該当サブセクション 1 箇所に集約する。
- **明確な境界**: 適用する。「経緯はノイズ・現在の事実のみ」という既存原則と、「補足情報としての close/ 参照は許容する」という本方針の境界を明記し、混同しない。

## 2. 変更内容

### 2.1 対象ファイルと変更点

| ファイル | 変更内容 |
| -------- | -------- |
| `.agent-skill-chain/project/自己拡張ワークフロー.md` | 「正本文書における close/ 参照の位置づけ（経緯・ADR 参照の扱い）」サブセクションを追加。正本は結論・現在の事実のみを記載する原則、close/ 参照は補足情報に限定する条件、`MODEL_TIER_TABLE.md` を実例として言及する記載を含む。 |
| 本 issue の `00_要求定義.md` | frontmatter `branch` を実ブランチ名に更新（実施済み）。 |

### 2.2 内容の要点（追加文の骨子）

- 正本には結論・現在の事実のみを記載する。
- close/ 配下 issue への参照は補足情報という位置づけに限定し、読めなくても本文の理解・運用に支障が出ないことを条件に許容する。
- `MODEL_TIER_TABLE.md` §裁量禁止との整合 の記載を、この方針に沿った実例として明示する。
- 満たさない書き方（close/ を読まないと結論が成立しない等）は今後の正本執筆で避ける。

### 2.3 参照関係・影響範囲

- 既存の「経緯はノイズ・現在の事実のみ」原則（ユーザーメモリ由来の運用方針）と矛盾しないよう、本方針は「正本内で結論が完結していること」を必須条件として明記し、両者を整合させる。
- `.claude/settings.json` の deny 設定自体には影響しない（00 §4.2 のとおり、本 issue は deny 設定を前提にしすぎない）。

## 3. テスト観点
