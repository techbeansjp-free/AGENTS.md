# 要件定義書: 配備済み hook と正本の乖離検知の仕組みを追加する

**プロジェクト名**: 配備済み PreToolUse.sh が正本より陳腐化しロックアウト既知バグ修正が未反映
**作成日**: 2026年07月14日
**最終更新**: 2026年07月14日

> **判断**: [00_要求定義.md](./00_要求定義.md) の対応方針（申し送り事項参照）どおり、**乖離を検知する仕組みの追加**で対応する。実際に本番 `.claude/` へ `upgrade` を実行し同期させる操作（今回 main にマージ済みの `PreToolUse.sh` 正本修正の反映）は、本 issue のスコープ外・別途ユーザー許可を得て orchestrator が手動実行する事項とする（00 §制約参照）。

---

## 1. 概要

配備済み `.claude/hooks/PreToolUse.sh`（各採用先で `.gitignore` 対象・setup/upgrade による生成物）は、正本 `.agent-skill-chain/source/enforcement/claude/PreToolUse.sh` を手で編集しても自動追従しない。正本側で既知バグ（orchestrator 完全ロックアウト等）を修正しても、配備済み環境で `upgrade` を実行しない限り旧版のまま放置され、修正済みのはずのバグが配備環境で再現しうる。本 issue では、この「正本 ⇔ 配備物」の乖離を **read-only で検知し警告する仕組み** を追加する。実際の同期（`upgrade` 実行）は行わない。

## 2. 機能要件

### 2.1 ユーザーストーリー

#### ストーリー 1: 保守者が配備済み hook の陳腐化を検知できる

- **As a** 本フレームワークの保守者・orchestrator
- **I want to** 配備済み `.claude/hooks/*.sh` が正本 `enforcement/claude/*.sh` と一致しているかを、任意のタイミングで read-only に確認できる
- **So that** 正本修正後に `upgrade` の実行漏れがあっても気付ける（過去のロックアウト事故の再発を防止できる）

**受け入れ基準**:

- 正本と配備物の内容が一致する場合、乖離検知スクリプトが `[OK]` を出力し終了コード 0 を返す。
- 正本と配備物の内容が異なる場合（内容不一致、または配備先にファイルが存在しない）、乖離検知スクリプトが `[DRIFT]` を出力し終了コード 1 を返す。
- `.claude/hooks/` が存在しない環境（enforcement 未 opt-in）では、乖離ではなく `[INFO]` 扱いとし終了コード 0 を返す（enforcement は既定 off であり、未配備自体は異常ではないため）。
- スクリプトは同期（ファイルの上書きコピー）を一切行わない（read-only diagnostic）。

### 2.2 非機能要件

- **セキュリティ**: 本スクリプトは読み取りのみを行い、`.claude/` 配下への書き込みは一切行わない。稼働中の他セッションの実行環境（メイン作業ツリーの `.claude/`）に影響を与えない設計とする。
- **保守性**: 比較対象ファイル一覧は `setup.sh` の `copy_owned_files` と同一規則（`enforcement/claude/` 配下のトップレベル通常ファイル、`.gitkeep` を除く）に揃え、正本の構造が変わってもハードコードの一覧を保守する必要がないようにする。
- **互換性**: `sha256sum` が無い環境（例: macOS）では `shasum -a 256` にフォールバックする。

## 3. 除外要件

- 実際に配備済み `.claude/` を書き換える操作（`upgrade` の自動実行・自動同期）は行わない（00 §5 除外要件・本 01 冒頭の判断のとおり）。
- `bin/agents-md.js`（CLI 本体）の変更は行わない（本 issue の対象ファイルは `.agent-skill-chain/source/` 配下に限定。CLI への配線は将来の別 issue とする）。
- CI（audit.sh）への組み込みは行わない（read-only の独立スクリプトとして提供し、将来必要になれば別 issue で検討する）。

## 4. 成功基準

- 正本と配備物に差分がある/ない両方のケースを tmp 隔離環境でシミュレートし、乖離検知スクリプトが期待どおりの `[OK]`/`[DRIFT]`/`[INFO]` と終了コードを返すことを確認する。
- 「hook に関わる正本修正が入った場合は `upgrade` を実行し配備物を同期すべき」という運用ルールが `enforcement/README.md` に明記される。
- 本番の `.claude/` への実同期はスコープ外である旨が 00/04 に申し送り事項として明記される。
