# 設計書: AGENTS.md 実在しない参照先の修正

**プロジェクト名**: AGENTS.md 実在しない参照先の修正
**作成日**: 2026 年 07 月 14 日
**最終更新**: 2026 年 07 月 14 日

> **用語**: [.agent-skill-chain/source/CONCEPTS.md §用語規約](../../../../../../../.agent-skill-chain/source/CONCEPTS.md#用語規約) を参照。

---

## 1. 設計概要

### 1.1 設計方針

参照先をディレクトリ丸ごと（`.agent-skill-chain/source/workflow`）ではなく、実在するファイル・節（見出し）に具体化する。

### 1.2 設計原則（本プロジェクトで適用するもの）

- **明確な境界**: 参照元（AGENTS.md）と参照先（PHASES.md）の対応を一意にし、曖昧な「関連ドキュメント」という表現を排除する。

---

## 2. アーキテクチャ設計

### 2.1 責務・境界・参照関係

#### 2.1.1 責務一覧

| コンポーネント | 責務（1 文） |
| --- | --- |
| `AGENTS.md`（入口案内） | issue 作成依頼時の自動委譲ルールの詳細参照先を示す。 |
| `.agent-skill-chain/source/workflow/PHASES.md` | issue 作成の詳細手順（作成場所・委譲・適用ルール）を定義する正本。 |

#### 2.1.2 境界

- **入力**: `.agent-skill-chain/source/workflow/` 配下 4 ファイル（PHASES.md・PHASE_COMMAND_MAP.md・SKILL_MANDATORY.md・TEMPLATES.md）の内容確認結果。
- **出力**: `AGENTS.md:62` の参照記載（PHASES.md の具体節への参照に修正）。
- **他責務との境界**: `.agent-skill-chain/source/workflow/` 配下ファイルの内容自体の変更は範囲外。

#### 2.1.3 参照関係

- `AGENTS.md` →（参照）→ `PHASES.md §一般的な issue 作成ステップ`。循環参照なし。

### 2.2 調査結果（根拠）

`.agent-skill-chain/source/workflow/` 配下の 4 ファイル（PHASES.md・PHASE_COMMAND_MAP.md・SKILL_MANDATORY.md・TEMPLATES.md）を確認した結果、PHASES.md 内に **「## issue_creation サブフェーズ」** 配下の **「### 一般的な issue 作成ステップ」** という節（31〜37 行目付近）が存在し、以下を規定している。

- 作成場所の上書き優先順位（`.agent-skill-chain/project/` 最優先）
- issue 作成依頼時のサブへの自動委譲（AGENTS.md §issue 作成依頼時のサブ自動委譲ルールと同一の適用ルール）
- 適用ルールの根拠（自己完結）

これは `AGENTS.md:62` が「詳細は... issue 作成関連ドキュメントを参照」として指し示そうとしていた内容と一致する。他の 3 ファイル（PHASE_COMMAND_MAP.md・SKILL_MANDATORY.md・TEMPLATES.md）には issue 作成そのものの詳細手順に相当する独立した節は無い。

#### ADR-1: 参照先の具体化方法

- **コンテキスト**: `AGENTS.md:62` の参照先「workflow 配下の issue 作成関連ドキュメント」は独立ファイルとして実在しない。実在するどの節を指すべきかを特定する必要がある。
- **検討した選択肢**:
  1. `PHASES.md §一般的な issue 作成ステップ` への具体参照に修正する。
  2. `.agent-skill-chain/source/workflow/` ディレクトリへの参照のまま、「関連ドキュメント」という文言のみを削除する。
- **決定**: 選択肢 1（PHASES.md の具体節への参照に修正）。
- **根拠**: PHASES.md §一般的な issue 作成ステップ の内容が、AGENTS.md:62 の文脈（作成して系/提案して系/説明して系の優先度判定に続く「詳細」）と実際に一致することを内容確認で検証した（evidence_source: existing_code）。ディレクトリ全体への参照のままでは「issue 作成関連ドキュメント」という誤解を招く表現の根本原因（存在しない独立ファイルへの言及）は解消されない。
- **帰結**: `AGENTS.md:62` の該当箇所を `.agent-skill-chain/source/workflow/PHASES.md §一般的な issue 作成ステップ` への具体参照（ファイル名＋節見出し）に修正する。
