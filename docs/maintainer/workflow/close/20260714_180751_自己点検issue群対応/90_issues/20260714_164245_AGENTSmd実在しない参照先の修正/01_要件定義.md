## 1. 概要

### 1.1 システム概要

`AGENTS.md:62` が「`.agent-skill-chain/source/workflow` 配下の issue 作成関連ドキュメントを参照」と記載しているが、当該ディレクトリには PHASES.md・PHASE_COMMAND_MAP.md・SKILL_MANDATORY.md・TEMPLATES.md の 4 ファイルのみが存在し、「issue 作成関連ドキュメント」という独立ファイルは無い。実在する具体ファイル・節への参照に修正する。

### 1.2 用語集

| 用語 | 説明 |
| --- | --- |
| PHASES.md | フェーズ順・成果物・DoD を定義する正本。`.agent-skill-chain/source/workflow/` 配下。 |
| issue 作成関連ドキュメント | AGENTS.md:62 が指していた（実在しない）参照先の名称。 |

---

## 2. 機能要件

### 2.1 ユーザーストーリー

#### ストーリー 1: 実在する参照先への修正

- **As a** 本フレームワークの利用者・エージェント
- **I want to** `AGENTS.md:62` の参照先が実在する具体的なファイル・節を指すこと
- **So that** issue 作成の種別判定（作成して系/提案して系/説明して系）の詳細を実際に探し当てられる

**受け入れ基準**:

- `AGENTS.md:62` の参照先が `.agent-skill-chain/source/workflow/PHASES.md` 内の実在する節（§一般的な issue 作成ステップ）を指す記載に修正されている。
- 当該節（PHASES.md §一般的な issue 作成ステップ）の内容が、AGENTS.md:62 が伝えようとしていた情報（issue 作成依頼時の作成場所・委譲・適用ルール）と一致している。

### 2.2 BDD ユースケース

#### ユースケース 1: 参照先の特定と修正

**シナリオ 1: workflow/ 配下から issue 作成に関連する節を特定する**

```gherkin
Feature: AGENTS.md:62 の参照先修正
  Scenario: PHASES.md 内に issue 作成関連の節が実在する
    Given .agent-skill-chain/source/workflow/PHASES.md に「一般的な issue 作成ステップ」という節が存在する
    When AGENTS.md:62 の参照記載を確認する
    Then AGENTS.md:62 は .agent-skill-chain/source/workflow/PHASES.md の当該節への具体的な参照に修正されている
```

### 2.3 ビジネスルール

- 参照先は実在するファイル・節（見出し）を指すこと。ディレクトリ丸ごとへの曖昧な参照を残さない。
