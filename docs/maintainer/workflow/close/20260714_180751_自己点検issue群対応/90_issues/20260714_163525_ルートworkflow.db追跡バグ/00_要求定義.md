## 1. 目的・背景

### 1.1 目的（必須）

ルート直下の追跡済み workflow.db（0バイト）を除去し .gitignore と整合させる。

### 1.2 背景

2026-07-14 fable による本システムの自己調査で検出。

- **現状の課題**:
  - `.gitignore` 自身が「正規の証跡DBは `.agent-skill-chain/runtime/workflow.db` のみ。ルート直下 workflow.db は追跡しない」と明記し `/workflow.db*` を ignore 指定している。
  - にもかかわらず、ルートの workflow.db は既に追跡済み（`git ls-files` に出現、0バイト）のため ignore が効かず残存している。
  - 「workflow.db の実体を絶対に含めない」という enforcement ルールと矛盾する。

- **必要性**:
  - .gitignore の宣言と実際の git 追跡状態を一致させる必要がある。

### 1.3 期待される効果（必須: 1 件以上）

- **効果 1**: `git ls-files` にルート直下 workflow.db が出現しなくなる。

**現状と期待される状態の比較**（必要に応じて）:
