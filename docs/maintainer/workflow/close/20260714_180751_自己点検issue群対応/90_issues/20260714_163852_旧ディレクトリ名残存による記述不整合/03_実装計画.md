## 5. リスク管理

### 5.1 実装リスク

- **リスク**: 意図的な後方互換記載（`SETUP.md` のレガシー移行パス、`package-manifest.sh` の `legacy_*` 変数等）や概念呼称としての `.agents`（`AGENTS.md:82,98` 等）を誤って書き換えてしまう。

- **リスク**: `self-enforce.yml` のコメント修正が外部参照禁止規約に抵触し、CI の Comment external-ref check を落とす。
  - **対策**: ローカルで `check-comment-refs.sh .github/workflows` を実行し、修正後に違反が無いことを確認した（タスク 5 §2.5.4 参照）。
