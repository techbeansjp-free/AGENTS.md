  - memo は `**/memo/*` で gitignore（必要時のみ個別に追跡）。
- **新ルール（本セッションで明文化・初適用）**:

- **作業方針（記憶済み）**: 外部アクセス無しで安全な作業は許可確認せず **auto 継続**。外部送信 / push / 破壊的操作 / 挙動変更時のみ確認を取る。

## 6. 進め方（新セッションが守ること）

1. **着手前に必ず読む**:
   - `.agents/boot/CORE.md`
   - `.agents/boot/LOAD_POLICY.md`
   - `.agents/workflow/PHASES.md`（§完了 issue の close 移動 を含む）
   - `.agents/skills/agent/run_command.md`
   - `.agents-project/自己拡張ワークフロー.md`（issue 配置・close 運用・tmp 隔離）
2. **orchestrator として進行**: phase 判定 → command 選択 → サブ委譲。
3. **実装後は必ず verify-and-close**: `04_review` を issue 直下に作成し、`write-workflow-log.sh` で `workflow.db` に記録する（prev_hash は自動連結）。
4. **テストは tmp 隔離**: `mktemp -d` ＋ `git archive HEAD | tar -x` 等で隔離環境を作って検証し、本リポの `.agents/` `.claude/` `.cursor/` `.workflow/` `workflow.db` を変更/破壊しない。
5. **完了したトップレベル issue は `close/` へ移動**（サブ issue 単独完了では移動しない。親完了時のみ）。証跡（04_review・台帳ログ）は移動後も保持。
6. **配置ルール**:
   - `04_review` は issue 直下。
   - memo は issue の `memo/` 配下に `TZ=Asia/Tokyo date +%Y%m%d_%H%M%S` プレフィックスで作成。
   - 台帳記録は `write-workflow-log.sh` 経由のみ（`sqlite3` 直接操作は禁止）。
