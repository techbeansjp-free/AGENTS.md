1. **【非成立・当初の指摘を誤報として撤回】無関係 issue の削除がコミットに混入していないか**
   - 攻撃: `git diff main --name-status` の 2-way diff で、`20260713_175839_サブエージェント背景タスク停止ガイドライン/00_要求定義.md`（issue_id ffe95495）が **D（削除）** と表示されることを発見し、当初これをブロッキング欠陥（指摘1）とした。

2. **【マイナー・成立】節4 本文が受け入れ基準（03 grep）・must-preserve に反していないか**
   - 攻撃: 03 §2.1.3 は「節4 本文に `不可逆`／`大量削除`／`履歴改変` が出ないこと」を受け入れ grep として定義。review-docs must-preserve #1 も「節4本文に『不可逆』を書かない」を不変条件化。実装後 節4 を grep → L32・L34 に「不可逆または広範囲な影響」が**2 箇所存在**。
