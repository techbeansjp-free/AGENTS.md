# 02_設計: #171 CI/gate運用の本番導入

**作成日**: 2026年07月20日

> 本Issueは既存CLI（`init`コマンド、Issue #169で実装済み）と既存設定ファイルの値変更のみで完結し、`src/`配下の新規設計・実装は不要である。本ドキュメントは「何を・どう実行するか」の手順設計に限定する。

---

## 1. 責務・実行手順

1. `npm ci`（`prepare`スクリプト経由で`tsc`ビルドが走り`bin/agents-md.js`が生成される。`bin/`は`.gitignore`対象のビルド生成物）。
2. `node bin/agents-md.js init --dry-run`で導入対象ファイル一覧を事前確認する（実書込みなし）。
3. `node bin/agents-md.js init`を実行し、dry-run結果と実行結果の作成対象ファイル一覧が一致することを確認する。
4. `.agent-skill-chain/config/agent-skill-chain.yaml`の`review.adapter: claude`を`review.adapter: human`へ手動編集する（`config.schema.yaml`が`enum: [claude, codex, human]`を既に許容しているため、schema変更は不要）。
5. `node bin/agents-md.js verify branch-name process/171-ci-gate-dogfood`でbranch名規約適合を確認する。
6. `npm test`を実行し、実測結果（pass/fail件数）を記録する。fail が発生した場合は原因をコード読解で特定し、`04_review.md`に正直に記載する（本Issoの成功基準「既存322件超のテストを破壊しない」の判定材料とする）。

## 2. 影響範囲

- **新規作成**: `.github/`配下18ファイル（`.agent-skill-chain/templates/github/.github/`からの展開結果、`init`が生成）。
- **変更**: `.agent-skill-chain/config/agent-skill-chain.yaml`の1行（`review.adapter`）のみ。
- **副作用として生成される既存ファイル**: `.agent-skill-chain/.installed_version`（`init`が新設するバージョンマーカー、Issue #169 T1で実装済み）。このファイルは`.gitignore`対象外であり、`test/helpers/tmp-repo.ts`の`createTmpRepo()`が`.agent-skill-chain/`ディレクトリ全体を「まだinit未実行の消費者リポジトリの雛形」としてそのままコピーする実装になっているため、本リポジトリでdogfooding目的で`init`を実行し`.installed_version`を作ると、そのままテストfixtureへ意図せず伝播する（詳細は`04_review.md`参照）。
- **src/配下**: 変更なし。

## 3. 設計判断

- **config schema**: `review.adapter`の`enum`は既に`[claude, codex, human]`を含んでおり（`.agent-skill-chain/schemas/config.schema.yaml`実測確認済み）、Issue本文が懸念する「schema検証でこける」リスクは値そのものについては存在しない。
- **branch.pattern適合**: `.agent-skill-chain/config/agent-skill-chain.yaml`の`issue.allowed_types`に`process`が既に含まれており（`[feature, bugfix, hotfix, refactor, docs, process]`）、`branch.pattern: "{type}/{issue_id}-{slug}"`に対し`process/171-ci-gate-dogfood`は`type=process, issue_id=171, slug=ci-gate-dogfood`として適合する設計であることを事前にコードで確認した。

## 4. 対象外

- claudeアダプタでの実AI判定の実地検証。
- doctor全項目網羅・WIP強制等の他ギャップ項目。
- `.installed_version`のテストfixture伝播問題自体の恒久修正（test/helpers側の改修）は本Issueのスコープ外とし、`04_review.md`のfalsificationとして記録するに留める。
