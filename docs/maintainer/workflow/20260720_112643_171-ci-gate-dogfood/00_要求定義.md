# 要求定義書: agent-skill-chain — CI/gate運用の本番導入とE2Eフロー実地一周

**作成日**: 2026年07月20日

> 本ドキュメントは GitHub Issue #171（techbeansjp-free/AGENTS.md）に対応する requirement-discovery フェーズの成果物である。Issue自体が小規模スコープと明記しているため、本ドキュメントは簡潔に記載する。

---

## 1. 目的・背景

### 1.1 目的

1. `init`コマンドを使い、このリポジトリ自身（統合ブランチ`chore/162-agent-skill-chain-bootstrap`）へ`.github/`一式（CI・gate・reconcile・risk workflow、Issue/PRテンプレート等）を導入する（ドッグフーディング開始）。
2. `review.adapter`を`claude`から`human`へ変更する（本リポジトリは実質1人開発のため、gate判定はAPIキー不要のhumanアダプタで運用する）。
3. 本Issue自体を実際にSPEC→DESIGN→IMPLEMENTATION→VALIDATIONの4segmentで処理し、gateが実際に機能することを実地で確認する。

### 1.2 背景

実装チェックリストとのギャップ分析の横断的所見13「E2Eフローを1周走らせた実績が一度もない」に対応する。このリポジトリ自身は`.github/`（配布用CI/gate workflow）を導入しておらず、`agent-skill-chain-ci.yml`・`agent-skill-chain-gate.yml`が実際にこのリポジトリで一度も稼働したことがない。

---

## 2. 機能要件

- `node bin/agents-md.js init`を実行し、`.github/`一式（CODEOWNERS、ISSUE_TEMPLATE、SECURITY.md、dependabot.yml、pull_request_template.md、workflows 4種）をリポジトリルートへ導入する。
- `.agent-skill-chain/config/agent-skill-chain.yaml`の`review.adapter`を`claude`から`human`へ変更する。

## 3. 非機能要件

- 既存322件超のテストを破壊しない（成功基準）。
- `verify branch-name`によりbranch名`process/171-ci-gate-dogfood`が新仕様に準拠することを確認する。

## 4. 制約条件

- base branchは`chore/162-agent-skill-chain-bootstrap`。
- 対象外: claudeアダプタでの実AI判定の実地検証（APIキー未設定のため）、doctor全項目網羅・WIP強制等の他ギャップ項目。

## 5. 成功基準

- `.github/workflows/agent-skill-chain-{ci,gate,reconcile,risk}.yml`がこのリポジトリで有効化される。
- `review.adapter: human`設定が反映される。
- 既存322件超のテストを破壊しない。
