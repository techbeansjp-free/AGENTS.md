## テスト観点

- **B（命名）**: 作成形コマンドの命名違反が確実に reject され、listing/削除/rename・曖昧・対象外は誤 block しない（fail-open/closed の非対称が正しく効く）。`-b` 無しの暗黙ブランチ名・オプション位置揺れ・パス付き git・`command`/`env` ラッパー・グローバルオプション（`-C`/`-c`/`--git-dir=`）を跨いでサブコマンドを正しく抽出できる。固有名の日本語（`worktree運用規律`）は通り、危険文字（`/`・空白・`;`・`..`・先頭`.`/`-`）は弾く。reject メッセージに期待パターン・got・fix example が含まれる。
- **C（退避）**: untracked を含む worktree の `remove`（`--force` 含む）・`clean -x/-X` の前に untracked が退避先へコピー保全され、退避後に削除が進み、退避先から復元可能。untracked が無ければ退避しない。退避処理失敗でも原本を壊さず正常削除を妨げない（WARN のみ）。保持期限超過エントリが lazy purge される。
- **B'（配置/走査除外）**: setup 実行後 `.worktree/.gitignore`（`*`＋`!.gitignore`）が存在し、`.worktree/` 配下に作成した worktree が `git status` に現れない（ルート `.gitignore` 不変）。`settings.json` deny に `.worktree/**` がミラーされ既存 `close/**` と共存する。
- **CI audit**: #40 が grandfather baseline に無い新規非準拠ブランチのみ FAIL、既存ブランチは SKIP/救済。#39 がルート起点 unbounded find の prune 欠落を検知し既存の scoped find は誤検知しない。非 git/未 gate は SKIP。
- **非破壊/互換**: 既存 #1〜#38・既存 hook テストがグリーン。対象外環境・内部エラーで allow に倒れロックアウトしない。

## 単体テスト

- `git_subcommand_of`: 各種プレフィックス/グローバルオプション/未知オプションでサブコマンド抽出（未知オプションは allow 側に自然落下）。
- `validate_name`: 日本語 accept／`a/b`（`/`混入）reject／`..` reject／先頭`.`・`-` reject／空 reject／`foo.lock` reject。
- `validate_worktree_path`: `.worktree/feature/20260716_143000/x/` accept／`../x` reject／`.worktree` 外 reject。
- R7 駆動（stdin JSON）: 準拠 add→exit0／非準拠 branch 作成→exit2＋メッセージ／`git branch -a`→exit0／`git worktree list`→exit0／非 git tree→exit0。
- `is_worktree_destroy`＋`worktree_untracked_rescue`: untracked あり remove→退避＋exit0／untracked なし→exit0退避なし／`git clean -xf`→検知／退避失敗→WARN＋exit0。
- lazy purge: 期限超過エントリのみ削除・期限内保持。
- `check_worktree_branch_naming`（#40）/`check_find_worktree_prune`（#39）: baseline 済み既存ブランチ SKIP／新規非準拠 FAIL／scoped find は非検知／root find prune 欠落 FAIL。

## 5. リスク管理

### 5.1 実装リスク
- **配備物が古い**（ADR-1・実測）: 正本改修後 `.claude/hooks/` 未同期だと本 issue の hook 改修が効かない。T6-1 で `setup.sh`/`upgrade` 再実行＋`check-hook-drift.sh` 確認を必須化。
- **#40 の初回誤 FAIL**: 既存の多数の非準拠ブランチ。grandfather baseline スナップショット（T4-1）と gate（既定 true だが baseline 不在時 SKIP）で SC-7 非破壊を担保。
- **C 退避の副作用/性能**: 大量 untracked のコピー時間。`.git` 実体除外・（任意）閾値 WARN。copy（move 不可）で原本保護。
- **deny 自動配布不可**（ADR-6）: `settings.json` deny は setup/enforce の非管理領域。消費者向けは手動ミラー手順を文書化（自動化しない前提を明記）。
- **hook 非経由削除**（残余リスク・01 §5）: 別プロセス/別ツールの削除は捕捉外。文書で限界を開示し隠さない。
