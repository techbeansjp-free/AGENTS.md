## 3. 各指摘の対応方針（案 → 確定）

- **finding-2・finding-7（グループ C・最優先）**: `commands/design-feature.md` の PROCESS step 0a 実行条件を「`experience_surface` が `null`（未記入）または `"yes: ..."` の場合に実行」へ改め、0a（frame-experience）自身が判定を担う設計と矛盾しないようにする。`workflow/SKILL_MANDATORY.md`・`TEMPLATES.md` の該当箇所も同じ条件表現へ揃える。設計判断（C2）を伴うため design-feature の PROCESS 定義変更として扱う。
