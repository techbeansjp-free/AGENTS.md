- **リスク**: S5（CLOSEOUT.md 新設）未完了時に編集先を取り違える。

- **リスク**: CLOSEOUT.md は S1/S2 と共有のため編集衝突する。
  - **対策**: §fresh サブ分割の 1 節内の加法的行追加のみに限定し他節に触れない（[02 §2.2.3](./02_設計.md)）。
