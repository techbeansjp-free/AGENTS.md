# 2. 画面設計

## 2.1 該当なし（CLI / 非 GUI）

本リポジトリは CLI ツール（`agents-md`）・bash スクリプト群・CI パイプラインで構成され、**GUI 画面を持たない**（`src/` に UI コンポーネントは存在しない）。したがって画面遷移図・画面項目定義は**該当なし**とする。

- **根拠**: 本セクションはテンプレート構造（[.agent-skill-chain/runtime/templates/docs/02_画面設計/](../../.agent-skill-chain/runtime/templates/docs/02_画面設計/)）を踏襲するため存置するが、非該当を明記する（空セクション放置ではなく事実の記載）。
- **ユーザーインターフェースの実体**: 対話インターフェースは CLI コマンド体系である。詳細は [04 機能設計/CLI](../04_機能設計/CLI/README.md) を参照。
- 将来 GUI を追加する場合にのみ本セクションを拡張する。
