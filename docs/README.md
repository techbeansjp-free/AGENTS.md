# 文書の利用範囲

現行v0.5の製品入口は[README](../README.md)、実行手順は[USAGE](../v05/USAGE.md)、権限と品質は[契約入口](../.agent-skill-chain/00_利用案内.md)を参照する。

`reviews/`、`evidence/`、`issues/`には、その記録に記載されたcommit・版に対する過去の検証・議論が残る。現行仕様や現在の合格証明として読み替えない。これらの記録に引用された旧path・リンクは対象commitのtreeで確認し、現行ファイルへ機械的に付け替えない。旧Stepの実行仕様は現行treeから除外し、必要時はGit履歴を参照する。

`PROJECT_MANAGEMENT.md`は本リポジトリのProject運用契約であり、利用者プロジェクトへ配布するWorkflowではない。`adr/`の判断は対象版と現在の配布契約を照合する。履歴を残すために新しいADRを自動生成しない。
