# FN-003 会員登録機能 個別機能仕様

状態: 承認済み（確認者: 業務責任者、根拠: 2026-11-20の打合せ）

- 目的: 利用者がメールアドレスまたは電話番号で会員登録できる。
- 関連要件: 未決（OPEN: REQ IDが未確認。確認先は要件一覧の管理者。影響は要件との対応が取れないこと）
- 関連ユースケース: 未決（OPEN: UC IDが未確認。確認先は要件追跡表の管理者。影響は追跡表の対応が取れないこと）
- 主体: 未決（OPEN: ACT IDが未確認。確認先は概要の利用者・関係者。影響は権限の参照先が決まらないこと）。必要な権限は[信頼境界・認証認可](../10_セキュリティ/01_信頼境界・認証認可.md)を正本とする。
- 前提条件: 登録手段として選んだメールアドレスまたは電話番号が、未登録である。
- 入力:
  - 登録手段は「メールアドレス」と「電話番号」のどちらか1つである。
  - 電話番号はE.164形式で受け付ける。
  - メールアドレスの形式・制約は未決（OPEN: 確認先は業務責任者。影響は入力検証の基準が決まらないこと）。
  - 確認コードは6桁の数字である。
- 出力:
  - 登録手段に対して、6桁の数字の確認コードを送る。
  - 確認コードの有効期限は、送信から15分である。
- 正常時:
  - 利用者が有効期限内の正しい確認コードを入力すると、会員登録が完了する。
  - 会員登録の完了後の状態（ログイン状態の有無等）は未決（OPEN: 確認先は業務責任者。影響は完了後の画面遷移が決まらないこと）。
- 失敗時:
  - 確認コードが誤っているとき、会員登録は完了しない。
  - 確認コードの有効期限が切れているとき、会員登録は完了しない。利用者は確認コードを再送信できる。
  - 確認コードを5回続けて間違えると、その登録手続きを30分ロックする。ロック中は会員登録が完了しない。
  - いずれの失敗でも、会員情報は作成されない。
- 不変条件:
  - 確認コードの桁数は6桁である。
  - 確認コードの有効期限は15分である。
  - 連続して間違えられる回数は5回までで、5回目の誤りでロックする。
  - ロック時間は30分である。
  - ロックの単位は登録手続きである。
- 互換性: 登録手段は、メールアドレスと電話番号の2つである。
- 対象外: 未決（CON IDが未確認。[制約・前提・対象外](../02_要件/02_制約・前提・対象外.md)を正本とする）。

- 受け入れ条件: 未決（OPEN: AC IDが未確認）。条件の正本は[受け入れ条件](../02_要件/01_受け入れ条件.md)、テストとの対応は[要件追跡表](../15_要件追跡/00_追跡表.md)とする。
