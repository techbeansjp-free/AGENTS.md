# FN-003 会員登録 個別機能仕様

状態: 提案（変更内容の決定者: 業務責任者 佐藤さん、根拠: 2026-11-20の打合せ。この仕様書の記述内容は未レビュー）

- 目的: 利用者がメールアドレスまたは電話番号で会員登録できるようにする。今回の変更で、電話番号による登録を追加した。

- 関連ユースケース: {UC ID。未確認。対応の正本は要件追跡先}
- 主体: {ACT ID。未確認。会員登録を行う利用者}。必要な権限は[信頼境界・認証認可](../10_セキュリティ/01_信頼境界・認証認可.md)を正本とする
- 前提条件:
  - 登録手段として、メールアドレスまたは電話番号のどちらか一方を選ぶ。
  - 入力された値が、すでに登録済みでないこと。重複時の扱いは OPEN-001 とする。
- 入力:
  - 登録手段がメールアドレスの場合: メールアドレス。形式の制約は従来どおり。
  - 登録手段が電話番号の場合: E.164形式の電話番号。
  - 確認コード: 6桁の数字。
- 出力:
  - 確認コードの送信先: 選んだ登録手段（メールアドレスまたは電話番号）。電話番号の場合の送信方法は OPEN-002 とする。
  - 登録結果: 成功または失敗。
- 正常時:
  1. 利用者が登録手段を選び、メールアドレスまたは電話番号を送信する。
  2. システムが6桁の数字の確認コードを生成し、選んだ手段で送る。
  3. 確認コードは、送信から15分間有効とする（変更前は10分）。
  4. 利用者が有効期限内に正しい確認コードを入力すると、会員登録が完了する。
- 失敗時:
  - 入力形式が不正な場合（電話番号がE.164形式でない場合を含む）: 確認コードを送らず、登録手続きを開始しない。表示は[SCR-005](../05_画面/02_個別画面テンプレート.md)に従う。
  - 確認コードが期限切れの場合: 登録は完了しない。「確認コードの有効期限が切れました。もう一度送信してください」を示し、確認コードを再送信できる。
  - 確認コードが誤っている場合: 登録は完了しない。誤りの回数を数える。
  - 確認コードを5回続けて間違えた場合: その登録手続きを30分間ロックする（この規則は変更前から変わらない）。ロック中は、その手続きでの確認コードの検証を受け付けない。
  - 失敗時に変更されないもの: 会員情報は、登録が完了するまで作成しない。
- 不変条件:
  - 確認コードは6桁の数字である。
  - 確認コードの有効期限は、送信から15分である。
  - 5回続けて誤るとロックし、ロック時間は30分である。
  - 電話番号はE.164形式のものだけ受け付ける。
  - 業務全体の規則は[業務規則](../01_システム概要/01_業務・利用者フロー.md)のBR IDで参照する。BR IDは未確認。
- 互換性:
  - 既存のメールアドレスによる登録は、従来どおり使える。
  - 変更前に送信済みで未使用の確認コードの有効期限をどうするかは、OPEN-003 とする。
- 対象外: {CON ID。[制約・前提・対象外](../02_要件/02_制約・前提・対象外.md)を正本とする。未確認}

## 未決事項

- OPEN-001: すでに登録済みのメールアドレスまたは電話番号が送信された場合の扱い。確認先: 業務責任者。影響: 失敗時の振る舞いと表示。
- OPEN-002: 電話番号への確認コードの送信方法（SMSなど）と、送信できなかった場合の扱い。確認先: 業務責任者と実装担当。影響: 外部連携先、費用、失敗時の振る舞い。
- OPEN-003: 変更前に送信済みで未使用の確認コードの有効期限（10分のまま扱うか、15分とするか）。確認先: 実装担当。影響: 互換性。

## アクセシビリティとレスポンシブ

- 見出し・ランドマーク・読み上げ順: 見出し、登録手段のタブ、選択中の入力欄、送信操作の順に読み上げる。タブは、タブ一覧とタブパネルとして関連付ける。
- キーボード・フォーカス: タブはキーボードだけで切り替えられる。タブを切り替えたとき、選択中のタブの状態を読み上げる。エラーを表示したときは、エラーのある項目へフォーカスを移す。期限切れの表示後は、再送信ボタンへ到達できる。
- 色以外の状態表現: タブの選択状態とエラーは、色だけでなく文言や形でも示す。
- 拡大・狭幅・言語長・動きを減らす設定: 拡大や狭幅の画面でも、タブとエラー文言が欠けず、横スクロールなしで読める。期限切れの文言は長いため、折り返して全文を表示する。動きを減らす設定では、タブの切り替えにアニメーションを使わない。
