# FN-003 会員登録機能

状態: 承認済み（確認者: 業務責任者、根拠: 2026-11-20の打合せ）

- 目的: 利用者がメールアドレスまたは電話番号で会員登録できる。
- 関連要件: 未決（OPEN: REQ IDが未確認。確認先は要件一覧の管理者。影響は要件との対応が取れないこと）
- 関連ユースケース: 未決（OPEN: UC IDが未確認。確認先は要件追跡表の管理者）
- 主体: 未決（OPEN: ACT IDが未確認。確認先はシステム概要の管理者）。必要な権限は[信頼境界・認証認可](../10_セキュリティ/01_信頼境界・認証認可.md)を正本とする。
- 前提条件: 登録に使うメールアドレスまたは電話番号が、未登録である。
- 入力:
  - 登録手段は、メールアドレスと電話番号のどちらか1つを選ぶ。
  - メールアドレスは、メールアドレスの形式で受け付ける。
  - 電話番号は、E.164形式で受け付ける。
  - 確認コードは、6桁の数字で受け付ける。
- 出力:
  - 登録手段に対応する宛先へ、6桁の数字の確認コードを送る。
  - 確認コードが正しいと、会員登録が完了する。
- 正常時:
  - 確認コードの送信後、確認コードの有効期限は15分である。
  - 有効期限内に正しい確認コードが入力されると、会員登録が完了する。
- 失敗時:
  - 確認コードが有効期限を過ぎると、登録は完了せず、確認コードの再送信を求める。
  - 確認コードが誤っていると、登録は完了せず、誤り回数が加算される。
  - 確認コードを5回続けて誤ると、その登録手続きを30分ロックする。
  - ロック中は、その登録手続きでの確認コードの入力を受け付けない。
  - いずれの失敗でも、会員情報は作成されない。
- 不変条件:
  - 確認コードは6桁の数字である。
  - 確認コードの有効期限は、送信から15分である。
  - 確認コードを5回続けて誤ると、その登録手続きを30分ロックする。
  - 電話番号はE.164形式だけを受け付ける。
- 互換性: メールアドレスでの登録と電話番号での登録は、同じ確認コードの規則に従う。
- 対象外: 未決（OPEN: CON IDが未確認。確認先は[制約・前提・対象外](../02_要件/02_制約・前提・対象外.md)の管理者）

- 受け入れ条件: 未決（OPEN: AC IDが未確認。確認先は[受け入れ条件](../02_要件/01_受け入れ条件.md)の管理者）。条件の正本は[受け入れ条件](../02_要件/01_受け入れ条件.md)、テストとの対応は[要件追跡表](../15_要件追跡/00_追跡表.md)とする。

  - 画面は、FN-003が登録の完了を返したときだけ、完了と表示する。
