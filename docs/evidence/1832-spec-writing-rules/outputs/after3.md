# FN-003 会員登録機能

状態: 提案（確認者: 未確認、根拠: 2026-11-20の打合せで業務責任者（顧客）が内容を決定）

- 目的: 利用者がメールアドレスまたは電話番号で会員登録できるようにする。
- 関連要件: 未決（OPEN-...）
- 関連ユースケース: 未決（OPEN-...）
- 主体: 会員登録を行う利用者（ACT ID は未決（OPEN-...））。必要な権限は[信頼境界・認証認可](../10_セキュリティ/01_信頼境界・認証認可.md)を正本とする
- 前提条件: 登録手段としてメールアドレスまたは電話番号のどちらか一方を指定する。
- 入力:
  - 登録手段は「メールアドレス」「電話番号」のいずれかである。
  - 電話番号はE.164形式で受け付ける。
  - 確認コードは6桁の数字である。
- 出力: 確認コードを、指定された登録手段（メールアドレスまたは電話番号）に送る。
- 正常時:
  - 利用者が登録手段を指定すると、確認コードを送る。
  - 確認コードが正しく、有効期限内であれば、会員登録が完了する。
- 失敗時:
  - 確認コードが期限切れの場合は、登録は完了しない。利用者は確認コードを再送信できる。
  - 確認コードを5回続けて間違えた場合は、その登録手続きを30分ロックする。ロック中は登録が完了しない。
- 不変条件:
  - 確認コードの有効期限は、送信から15分である。
  - 確認コードの連続誤入力が5回に達すると、その登録手続きを30分ロックする。
  - ロックは登録手続きごとに適用する。
- 互換性: 未決（OPEN-...）
- 対象外: 未決（OPEN-...）

- 受け入れ条件: 未決（OPEN-...）。条件の正本は[受け入れ条件](../02_要件/01_受け入れ条件.md)、テストとの対応は[要件追跡表](../15_要件追跡/00_追跡表.md)とする
