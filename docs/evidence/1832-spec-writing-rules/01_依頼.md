# 依頼（仕様書の更新）

会員登録機能（FN-003）と会員登録画面（SCR-005）の仕様書を、次の変更に合わせて書き直してほしい。

- これまで会員登録はメールアドレスだけだったが、今回から電話番号でも登録できるようにした。
- 登録時に送る確認コードは6桁の数字。有効期限は以前は10分だったが、問い合わせが多かったので15分に延ばした。
- 確認コードを5回続けて間違えると、その登録手続きを30分ロックする（これは前から変わらない）。
- 電話番号はE.164形式で受け付ける。
- 画面では、登録手段を「メールアドレス」「電話番号」のタブで切り替える。前はメールアドレスの入力欄だけだった。
- 確認コードが期限切れのときは「確認コードの有効期限が切れました。もう一度送信してください」と表示し、再送信ボタンを出す。
- この変更は2026-11-20の打合せで顧客の佐藤さん（役割：業務責任者）が決めた。
