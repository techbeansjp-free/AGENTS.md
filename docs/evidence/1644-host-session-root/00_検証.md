## 実装と要求対応

位置引数をレビュー対象として維持し、Gitのworktree一覧の主要checkoutを起動rootに自動解決する。main/rootは一覧の所属先、指定worktreeは読取り対象。Claudeはrootで起動して`--add-dir`で対象を追加し、改名も同じrootで行う。CodexはApp Serverプロセスとthread/startのcwdをrootにし、turn/startで所属cwdを変更しない。

両Hostの追加指示に対象の絶対path・HEAD・対象側規約の読取りとmainへの代用禁止を含め、状態にtargetDirectory/targetHeadを保存。本体終了時のHEAD変化は結果を保持して失敗とし、完了改名しない。非Gitでは従来どおり指定directoryで起動する。壊れたGit・bare構成・同一repoを証明できないrootでは起動前に停止する。必須権限、既存命名、非永続選択、改名失敗時の結果保持は維持。
