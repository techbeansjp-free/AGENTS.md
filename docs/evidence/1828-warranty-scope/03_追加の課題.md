# 課題（2件）

各課題に600字以内で答える。課題に書かれていない値は「未決」として扱う。

## T5 契約書にすでに定めがある案件
受託の業務システムで、締結済みの請負契約書に「契約不適合責任の期間は検収完了後1年」「乙は甲の指示または甲が提供した資料に起因する不適合については責任を負わない」との条項がある。これから仕様書に品質保証範囲の文書を足し、顧客と合意したい。品質保証範囲に何を書き、何を書かないか、契約書とどう関係づけるかを示してほしい。

## T6 検収の後に不備が分かった
半年前に検収を終えた受託システムで、顧客から「月末に締めた売上が、特定の条件で二重に計上される」と連絡があった。仕様書には売上の締め処理の業務規則（BR-012）と受け入れ条件（AC-040）があり、品質保証範囲（WAR）も合意済みである。この連絡をどう扱えばよいか、顧客への最初の返答の案も含めて示してほしい。
