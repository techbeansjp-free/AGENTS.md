# 閲覧環境で使える書体

この画面は外部通信のない環境で表示される。Web Fontの読込み（Google Fonts等のURL、`@import`）は使えない。閲覧環境に入っている書体は次のとおり。これ以外を指定した場合は代替書体で表示される。

- Noto Sans CJK JP（`"Noto Sans CJK JP"`、ゴシック体、weight 100〜900）
- Noto Serif CJK JP（`"Noto Serif CJK JP"`、明朝体、weight 200〜900）
- DejaVu Sans / DejaVu Serif / DejaVu Sans Mono
- Liberation Sans / Liberation Serif / Liberation Mono
- 汎用名：`sans-serif`、`serif`、`monospace`
