# 依頼：バス停の発車案内（スマートフォン向け）

ある市（架空）のコミュニティバスが、バス停に掲示したQRコードから開く発車案内のページを1枚作りたい。データは `data.json`（同じフォルダ）にある。この画面ではデータをファイル内に埋め込んでよい（取得処理の実装は不要）。

## 利用者と使い方

- バス停で待つ人。通勤・通学の人、通院する高齢の人、子ども連れの人。ほとんどがスマートフォン（幅390px程度）で、片手で、屋外で見る。PCで開く人もいる。
- 開いてすぐに「次のバスはいつ来るか、遅れや運休はないか、どののりばか」を判断する。

## 必ず満たすこと

- バス停名と、データにある全ての便（5便）の路線・行先・のりば・時刻予定・状態を示す。
- 遅れの便は、予定時刻と見込み時刻・遅れの分数を示す。運休の便は、運休であることを示す。状態（定刻・遅れ・運休）は色だけに頼らずに区別できる（文字・記号などを併用）。
- 運行のお知らせ（`notice`）を、初期表示の範囲（スマートフォンで最初に見える範囲）で示す。
- 最終更新時刻、運賃、問合せ先を示す。
- 低床車両の便が分かる。
- 指で押す要素は十分な大きさにし、幅390pxで横にはみ出さない。

## 制約

- 単一のHTMLファイル（CSS・JavaScriptはファイル内に書く）。外部のURLから書体・スクリプト・ライブラリを読み込まない。
- 使える書体は `FONTS.md`（このフォルダ） を参照。

## 成果物

- `out/index.html`
- `out/DESIGN-NOTES.md`：主要な設計判断（情報の優先順位・配色・書体・構図など）と、それぞれをこの依頼のどの内容・利用者に対応させて選んだかを、短く書く。参考にしたものがあれば出典と、確認した範囲を書く。
