## 採否

EVAL_PLANの基準に当てはめた。
- Bは、過去の評価基盤の不備のうち3件（I2・I4・I6）を、モデル呼出し0回で本試行の前に検出した。
- 準備時間（作成約3分、実行11〜17秒）は、I2の再実行（Verifier 9件。3件ずつ並列で、各回の最長は31〜37秒）とI1の破棄分を下回る。
- 採点器・goldを変えないので、採点精度と独立性は下がらない。

以上から**限定改善候補**とする。Cは、Bで検出できないI1型（モデルの振る舞いによる収集失敗）にだけ意味がある。そのためCは、条件付きでBに加える。

採らないもの：
