# 83原則の汎用化先と適用条件

提供資料の原則番号を参照し、再利用できる判断を公開用に書き直した。原資料の発言・案件・人物評価は転載しない。個人版を正しさの正本や安全性の証明として扱わない。

「対応」は明示された手順への対応であり、Skillを読むだけで実装や判断の有効性を保証する意味ではない。「部分」は汎用化できる判断の記載が不足するもの、「一部除外」は個人の育成・作業分担の好みを採用しない部分を表す。過去案件の強い固定値を条件付きの判断へ変えることは未対応に数えない。対象ごとに必要な観点を選び、83項目の全件回答や追加工程を通常作業へ要求しない。

適用先の略号：EJ = [engineering-judgment](../../../skills/engineering-judgment/SKILL.md)、条件 = [適用条件と反例](../../../skills/engineering-judgment/references/conditions-and-counterexamples.md)、PF = [project-foundation](../../../skills/project-foundation/SKILL.md)、PF契約 = [契約・型・画面・データ](../../../skills/project-foundation/references/contracts-and-ui.md)、PF検証 = [検証・セキュリティ・証跡](../../../skills/project-foundation/references/verification-and-security.md)、研究 = [research-to-implementation](../../../skills/research-to-implementation/SKILL.md)、規約 = [contract-enforcement](../../../skills/contract-enforcement/SKILL.md)、レビュー = [review-and-remediation](../../../skills/review-and-remediation/SKILL.md)、移行 = [migration-assurance](../../../skills/migration-assurance/SKILL.md)（[受入reference](../../../skills/migration-assurance/references/acceptance-and-cutover.md)）、監査 = [security-evidence](../../../skills/security-evidence/SKILL.md)、操作 = [user-journey-acceptance](../../../skills/user-journey-acceptance/SKILL.md)、高速化 = [verification-optimization](../../../skills/verification-optimization/SKILL.md)（[同等性reference](../../../skills/verification-optimization/references/equivalence-and-reuse.md)）、調整 = [work-coordination](../../../skills/work-coordination/SKILL.md)、復旧 = [execution-recovery](../../../skills/execution-recovery/SKILL.md)、ASC = [asc](../../../skills/asc/SKILL.md)、見積 = [estimate-and-scope](../../../skills/estimate-and-scope/SKILL.md)。
