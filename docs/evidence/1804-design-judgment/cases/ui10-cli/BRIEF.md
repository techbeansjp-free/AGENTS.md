# 依頼：CSV集計CLIの不具合修正

`src/summarize.mjs` は、CSVファイルを読み、列ごとの合計を表示するCLIです。

不具合：1行目（見出し行）が数値として合計に含まれ、見出しの列名が `NaN` になることがある。また、最終行が空行のCSVで、空行が0として件数に数えられる。

- 見出し行を合計に含めないこと、末尾の空行を数えないことを修正してください。
- `test/summarize.test.mjs` に、この2つの不具合の再発を確かめるテストを追加してください（Node.js標準の`node:test`を使う）。
- 出力の形式（`列名: 合計 (件数)`）は変えない。
