# 依頼：既存の管理画面に「請求先の編集」画面を追加する

会員制サービス（架空）の管理画面に、契約者が請求先情報を編集する画面を追加したい。管理画面には既存のデザインシステムがある（`app/tokens.css`、`app/components.css`、`app/DESIGN-SYSTEM.md`）。既存画面の例は `app/members.html`。

## 画面の要件

- 入力項目：請求先の名称（必須、50文字以内）、部署名（任意）、担当者名（必須）、メールアドレス（必須、形式の確認）、郵便番号（必須、7桁の数字、ハイフンは任意）、住所（必須）、電話番号（任意）。
- 「保存」で入力を確認し、誤りがあれば、どの項目をどう直せばよいかを項目の近くに示す。入力した内容は消さない。
- 保存中は保存ボタンを押せない状態にする。保存の成功・失敗を画面に示す。保存処理は模擬でよい（例：1秒後に成功。メールアドレスが`fail@example.com`のときは失敗）。
- 閲覧権限しかない利用者向けに、編集できない理由を示した状態も用意する（URLの`?role=viewer`で切り替えればよい）。

## 制約

- 既存のデザインシステムに従う。既存のファイル（`app/`内の既存ファイル）は変更しない。
- 新しい画面は `app/billing.html` として作る。画面専用のCSSが必要なら `app/billing.css` を作ってよい。
- 外部のURLから書体・スクリプト・ライブラリを読み込まない。

## 成果物

- `app/billing.html`（必要なら `app/billing.css`）
- `out/DESIGN-NOTES.md`：主要な設計判断と、それぞれをこの依頼・既存のデザインシステムのどれに対応させたかを、短く書く。
