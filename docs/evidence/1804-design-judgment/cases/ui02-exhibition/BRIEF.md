# 依頼：企画展の案内ページ

港町の市立郷土資料館（架空）が、企画展の案内ページを1枚作りたい。来館を検討している人が、行くかどうか・いつ行くか・どう行くかを決められるようにしたい。

## 利用者

- 市内・近隣の家族連れ、高齢の来館者、観光で訪れた英語話者。
- 多くはスマートフォンで見る。PCで見る人もいる。

## 企画展の内容（このページに必ず載せる）

- 展覧会名：「干潟と海苔の百年 ― 舟と手仕事の記録」

- 英語の概要（2〜3文）：上の概要に相当する内容。
- 会期：2027年4月10日（土）〜6月27日（日）
- 開館時間：9:30〜17:00（入館は16:30まで）
- 休館日：月曜日（祝日の場合は翌平日）
- 観覧料：一般 400円、高校・大学生 200円、中学生以下・65歳以上・障害者手帳をお持ちの方と介助者1名は無料
- 会場：市立郷土資料館 2階 企画展示室（住所：港南区汐見町3-14）
- アクセス：汐見駅 南口から徒歩8分。駐車場 12台（無料）
- 関連イベント（各回 定員20名・事前予約制・参加無料）

- 予約：関連イベントは電話（045-000-1234、9:30〜17:00）またはWeb予約フォーム（`#reserve`へのリンクでよい）
- バリアフリー：エレベーターあり、車いす貸出2台、多目的トイレ1階
- 問合せ：電話 045-000-1234
