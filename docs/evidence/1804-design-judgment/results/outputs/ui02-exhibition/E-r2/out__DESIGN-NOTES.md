# 設計メモ

## 判断と対応

| 判断 | 内容 | 対応する依頼内容・利用者 |
|---|---|---|
| 情報の順序 | 展覧会名・会期 → 要点4つ（会期／開館時間／休館日／観覧料）→ 概要 → 関連イベント → 予約 → 観覧料詳細 → アクセス → バリアフリー → 問合せ → English | 「行くか・いつ・どう行くか」の順に決められるようにするため。最初の1画面で日程と時間、休館日を読める。 |
| 英語の置き場所 | 最上部の帯に「English information」リンク、下部に英語セクション（概要2文＋日時・料金・アクセス等） | 英語話者が探さずに見つけられ、日本語主のまま保つ。展覧会の英語名はヒーローにも表示。 |
| 配色 | 干潟の青緑（#17404f）、紙色の地（#f6f1e6）、海苔の暗緑、強調に錆色（#a8441f） | 主題（干潟・海苔・舟）から。白文字と青緑、錆色は十分なコントラストを確保（目視ではなく概算：いずれも約7:1／5.5:1以上）。 |
| 書体 | 見出し・日付・金額は Noto Serif CJK JP、本文は Noto Sans CJK JP。外部読込みなし | 資料館らしい落ち着き＋本文の可読性。FONTS.md の範囲内。 |
| 文字サイズ | 本文18px（PC 19px）、要点は約22px、ボタン高さ48px以上 | 高齢の来館者、スマホ中心。電話は `tel:` リンク。 |
| 写真の代わり | インラインSVGで干潟・海苔ひび・ベか舟を描いた図 | 写真が無いため。外部画像不使用。代替テキスト付き。 |
| 休館日の強調 | 錆色で「月曜日」を表示 | 来館日の失敗（休館日に行く）を避ける。 |
| 観覧料 | 要点は一般料金のみ、詳細は表で全区分 | 家族連れ・高齢者が自分の区分を探しやすくする。 |
| 予約導線 | イベント直下に「予約する」(#reserve)と電話ボタン | 定員制・事前予約のため。 |
| レイアウト | 1カラムを基本、720px以上で2カラム | スマホ中心、PCでも読みやすく。 |

## 補足・未確認
- 参考にした外部サイト・資料はなし（FONTS.md と BRIEF.md のみ）。
- ブラウザでの表示確認、実機確認、コントラスト比の計測は**行っていない**。コントラストは配色からの見積り。
- Web予約フォームは依頼どおり `#reserve` への仮リンクで、フォーム本体は「準備中」の表記。
- 英語イベント説明で「予約は日本語対応」と書いたのは仮定。実際の対応言語は館に確認が必要。
- 概要の英訳と英語のイベント名は私の訳。館側の確認が必要。
