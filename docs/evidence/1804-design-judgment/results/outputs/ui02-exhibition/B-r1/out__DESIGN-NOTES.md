# 設計メモ

## 配色
- 海苔の黒緑 `#1d3832`（ヒーロー・フッター・予約帯）、干潟の砂色 `#eef0ea`（地）、藁色 `#d9c68f`（強調・ボタン）、藍 `#1f4a78`（見出し線・リンク）。
- 対応：題材（海苔・干潟・舟）の色そのものから取った。展示の主題に直結させ、汎用的な配色（クリーム＋テラコッタ等）を避けた。
- 本文 `#1b2824` と地の組合せは十分なコントラスト。高齢の来館者向けに本文・ボタン文字は濃色を使い、薄い色は暗地の上だけに限った。

## 書体
- 見出し・日付：Noto Serif CJK JP（weight 900）。海苔すきや日記の「手仕事」の印象。本文・表：Noto Sans CJK JP（小さい字でも読みやすい）。
- 本文は18〜19px、行間1.85。高齢の来館者とスマートフォン閲覧への対応。外部書体は読み込まない（FONTS.md の範囲のみ）。

## 構図・情報の順序
1. ヒーロー：展覧会名（和・英）と会期・会場を最初に置く。「行くかどうか」の判断材料。
2. 来館の要点（会期・開館時間・休館日・観覧料）：「いつ行くか」。無料対象を藁色で目立たせた（家族連れ・高齢者に関係が大きい）。
3. 展覧会について → 関連イベント（日付を大きく、予約ボタンを直下に）→ 行き方・設備：「どう行くか」。
4. 英語：上部に「English information」リンク、ヒーローに英語名、ページ下部に英語の独立節（`lang="en"`）。会期・時間・料金・行き方・予約まで英語だけで完結する。
- ヒーローの絵：写真が無いため、竹ひび（海苔網）と一人乗りの平底舟をインラインSVGで描いた。ページ読込み時に潮が引く動きが1回だけ入る（`prefers-reduced-motion` では停止）。
- イベントは順序のある手順ではないので、番号ではなく日付を見出しにした。カードの羅列にせず罫線の一覧にした。
- 電話は `tel:` リンクにし、スマートフォンから押せるようにした。ボタンは高さ3.25rem以上。キーボードフォーカスを表示。

## 判断・未確認事項
- 英語の概要は依頼文からの訳。展示名中の「ベか舟」は *beka* boat とし説明を添えた。
- 休館日の「祝日の場合は翌平日」は依頼文のまま掲載し、会期中の具体的な休館日は計算していない（資料館に要確認）。
- Web予約フォームは依頼どおり `#reserve`（同ページ内）へのリンク。実際のURLが決まったら差し替える。
- イベントの言語（英語対応の有無）は依頼に無いので書いていない。
- 曜日は2027年の暦で確認済み（4/10・6/27・各イベント日）。
