# 設計メモ

## 判断の軸
利用者（家族連れ・高齢者・英語話者、主にスマホ）が「行くか／いつ／どう行くか」を決める。最初の画面で題名・会期・時間・料金・行き方が見えることを優先した。

| 判断 | 内容 | 対応する依頼内容・利用者 |
| --- | --- | --- |
| 配色 | 地は干潟の砂色、ヒーローと予約帯は海苔の黒緑、日付の強調は舟の錆色、リンクと英語ブロックは潮の青。色は役割ごとに固定（錆＝日付・項目名、青＝リンク・英語）。 | 題材が干潟・海苔・ベか舟。本文は砂地に濃い泥色で高いコントラストにし、高齢の来館者に配慮。 |
| 書体 | 題名・見出し・日付・金額は Noto Serif CJK JP（太字）、本文・表示は Noto Sans CJK JP。英文は Liberation 系にフォールバック。本文18px・行間1.85。 | FONTS.md の範囲内。明朝の題名で展覧会の格を出し、読む文はゴシックで読みやすく。 |
| 構図 | 暗いヒーローに題名・英語名・会期・主ボタン。直下に会期／時間／料金／行き方の4項目帯。その後に概要、英語、イベント、来館案内。 | 「行くか・いつ・どう行くか」を判断する順。狭幅では1列、広幅では2列／3列に組み替え。 |
| 写真の代わり | 写真が無いため、干潟・海苔ひびの杭・ベか舟を描いたインラインSVGを使用（外部画像なし、`role="img"` と代替文あり）。 | 展示資料そのものを模した図で題材を示す。 |
| 英語 | ヘッダーに「English」リンク、ヒーローに英語名、概要直後に英語ブロック（概要・会期・料金・会場・アクセス等）。`lang="en"` を付与。 | 観光の英語話者が見つけやすい位置に。 |
| イベント | 日付を大きく出したカード3枚。定員・予約制・無料を冒頭に1回記載。予約帯に電話番号を大きく置き `tel:` リンクにした。 | 高齢の来館者は電話、スマホはタップで発信。 |
| 操作 | ボタンは高さ48px以上、フォーカス枠を明示、スキップリンクあり。 | 高齢者・スマホ操作。 |
