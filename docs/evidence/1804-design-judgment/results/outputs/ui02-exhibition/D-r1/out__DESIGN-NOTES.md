## 設計判断と対応
| 判断 | 内容 | 対応する依頼内容・利用者 |
|---|---|---|
| 情報の順序 | 展覧会名 → 会期・時間・休館日・料金（ヒーロー内）→ 概要 → 開催情報 → イベント・予約 → アクセス/バリアフリー → 英語 | 利用者の問い「行くか・いつ・どう行くか」。判断材料の会期・料金を最初の画面に置く。 |
| 英語の置き方 | 最上部の帯に `English information ↓` を固定。ページ末に `lang="en"` の英語節（概要・会期・料金・アクセス・予約）。ヒーローに英語名 | 英語話者が探さずに見つけられる。日本語が主なので本文は日本語を先に。 |
| 配色 | 干潟の泥色の地（#f4f0e6）、海苔の黒緑の文字（#1c2a26）、潮の青緑（#1e5563）のヒーロー。予約の操作だけに赤茶（#a8431f） | 題材（干潟・海苔・海）から取った。赤茶は「予約」専用にして、操作の場所を一色で示す。文字は地との明暗差を大きく取り、高齢者の可読性を優先（コントラスト比は暗算の概算で10:1超。測定ツールでは未検証）。 |
| 書体 | 見出し・日付・展覧会名は Noto Serif CJK JP（太字）、本文は Noto Sans CJK JP。英語節は Noto Serif（無ければ Liberation Serif） | `FONTS.md` の範囲。明朝は「記録・古い写真」の佇まい、ゴシックは情報の読みやすさ。本文 18px（広幅 19px）、行間 1.8。 |
| 写真の代わり | インライン SVG の絵（干潟、ベか舟、海苔ひび）。装飾で `aria-hidden` | 写真が無い。外部画像不可。題材の実物（舟・ひび）を単純な形で描いた。 |
| イベント | 日付を大きな数字にしたカード3件、その直下に予約枠（電話番号を大きく、`tel:` リンク） | 日付で選ぶ人が多い。スマホではタップで発信。`#reserve` は予約枠そのもの。 |
| 操作サイズ | ボタン・リンクの高さ 48px 以上、フォーカスは太い輪郭 | 高齢者・スマホ利用。 |
| 狭幅 | 1カラム。広幅（48rem〜）でヒーローを2段組、開催情報は項目名と値の2列 | スマホ中心。PCは余白を使って読みやすく。 |
