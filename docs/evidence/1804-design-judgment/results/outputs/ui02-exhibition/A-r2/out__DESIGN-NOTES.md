# 設計メモ

## 配色
- 深い青緑(`--sea` #17414d)＋海苔の緑(`--nori`)＋和紙色の地(`--paper`)＋錆色(`--rust`、休館日・フォーカス枠のみ)。
- 対応:テーマが海苔養殖・干潟。写真が無いため、色で題材を伝える。本文は濃い墨色を和紙色の地に置き、高齢の来館者でも読めるコントラストにした。
- 休館日だけ錆色にして、「いつ行くか」の判断で見落とされやすい月曜休館を目立たせる。

## 書体
- 見出し:Noto Serif CJK JP(明朝)。展覧会名に「記録・手仕事」の落ち着きを出す。
- 本文:Noto Sans CJK JP。スマホで読みやすいゴシック、本文18px・行間1.85(高齢者・スマホ)。
- 英語部分も同じ書体系。外部フォントは読み込まず、`FONTS.md` の範囲に限定。

## 構図と情報の順序
1. 最上部の細い帯に「English information」リンク → 英語話者が最初の画面で見つけられる。
2. ヒーロー:展覧会名・英語名・会期・開館時間・予約ボタン。
3. 要点3つ(会期／開館時間・休館日／観覧料)のカード → 「行くか・いつ行くか」を1画面で判断できる。
4. 展覧会について → 英語の概要と情報(日本語本文の直後)→ 関連イベント → 予約 → 来館案内(観覧料・アクセス・バリアフリー)。
- 写真の代わりに、ベか舟と海苔ひびの干潟をインラインSVGで描いた(外部画像なし、`role="img"`と代替テキストあり)。実際の資料写真が揃ったら差し替え可能。
- スマホは1カラム、PC(44rem以上)で2〜3カラム。電話番号は`tel:`リンクで押しやすく(ボタン高さ3rem以上)。
- 英語セクションには会期・時間・料金・アクセス・イベント・予約方法を要約し、英語だけで来館判断ができるようにした。

## 実装上の注意
- 単一HTML、CSS内蔵、JavaScriptなし、外部通信なし。
- `lang`属性を英語部分に付与、スキップリンク、フォーカス表示、`prefers-reduced-motion`対応。
