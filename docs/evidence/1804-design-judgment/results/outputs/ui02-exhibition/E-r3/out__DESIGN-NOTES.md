# 設計メモ：企画展「干潟と海苔の百年」案内ページ

## 情報の順序
1. **展覧会名・英語名・会期**（ヒーロー）→ 来館検討者がまず「何が・いつ」を知る。
2. **要点3つ帯**（会期／開館時間・休館日／観覧料）→ スマートフォンで1画面以内に「行くか・いつ行くか」を判断できる。
3. **English Information**（概要＋日時・料金・会場・アクセス・イベント・設備の要約）→ 英語話者が、ページ上部（スクロール前半）で見つけられる位置に置いた。ヘッダーにも「English information」のページ内リンクを置いた。
4. 展覧会の概要 → 観覧案内 → 関連イベント＋予約 → アクセス → バリアフリー → 問合せ。判断（行くか）→ 日程 → 参加 → 行き方の順。
- 予約ボタンはイベント一覧の直後に置き、電話（`tel:`リンク）を第一、Web予約（`#reserve`）を第二にした。高齢の来館者は電話の方が使いやすいと想定した（想定であり検証していない）。

## 配色
- 深い海色（#17414d）＋ 紙色（#f6f1e6）＋ 海苔の緑（#2f4a2c）＋ 錆朱（#a8431f、予約など「行動」だけに使用）。海苔養殖・干潟という主題から選んだ。
- 本文は #1c2a2e／紙色で、十分なコントラストを確保（概算で10以上。ツールでの実測はしていない）。

## 書体
- 見出し・日付・料金：Noto Serif CJK JP（資料館・記録の落ち着き）。本文・表：Noto Sans CJK JP（小さい字でも読みやすい）。`FONTS.md`の範囲内で指定し、外部読込みなし。
- 本文は17px相当・行間1.8。高齢の来館者に配慮。

## 写真の代わり
- インラインSVGで、ベか舟・海苔ひび・干潟を単純な線と面で描いた。外部画像なし。装飾なので過度な意味は持たせず、代替テキストで内容を説明。実写真が揃えば差し替える想定。

## 構図・操作
- 1カラムで、スマホ・PCとも同じ順序（PCは最大幅60rem）。表は狭い画面で項目名を上に積む。
- ボタン・リンクの高さは約56px以上。フォーカス枠あり。`lang`属性を英語部分に付与。

## 注意・未確認
- 仮置き：Web予約フォームのリンク先は`#reserve`（依頼どおり）。
- 祝日の月曜（例：5月の連休）の実際の休館日は依頼に無く、記載していない。
- 英語の概要は依頼文から私が訳した。公開前に館の確認が必要。
- 参考にした外部サイト・文献はなし（フォルダ内の`.claude/skills`の資料も参照していない）。実機・ブラウザでの表示確認、スクリーンリーダー確認、色コントラストの実測は**未実施**。
