# 設計メモ：企画展「干潟と海苔の百年」案内ページ

## 先に決めたこと
利用者（家族連れ・高齢の来館者・英語話者、多くはスマホ）が、**行くか・いつ行くか・どう行くか**を判断できること。主役は展覧会名と会期。

## 主要な判断と対応
| 判断 | 内容 | 対応する依頼内容・利用者 |
| --- | --- | --- |
| 情報の順序 | 題名＋会期（ヒーロー）→ 開館時間・休館日・料金・アクセスの4項目帯 → 展覧会概要 → 来館情報の詳細 → イベント → 予約 → アクセス/バリアフリー → 問合せ → English | 「行くか」は題名・概要、「いつ」は会期・時間・休館日、「どう行くか」はアクセス。スマホの最初の1〜2画面で日付と要点が見える |
| 配色 | 地は和紙色（`#f5f1e6`）、文字は海苔の黒緑（`#1b2a26`）、見出し帯・ボタンは干潟の水の深い緑青、イベント日付のみ錆色の強調 | 題材（海苔・干潟）から採った色。本文は高コントラストで高齢の来館者に配慮。強調色は日付だけにして役割を一つに限定 |
| 書体 | 題名・見出し・日付・料金にNoto Serif CJK JP（太字）、本文・表にNoto Sans CJK JP。本文は約17px、行間1.85 | FONTS.mdの範囲内。明朝の太字は「記録・手仕事」の題材に合わせ、数値や日付は目立たせる。本文はゴシックで可読性優先 |
| 構図 | 狭幅は1カラム、広幅は来館情報とアクセスを2カラムに。4項目帯は狭幅で縦積み、広幅で横並び | スマホ中心。PCでは表を並べて見比べやすくする |
| 写真の代わり | インラインSVGで干潟・海苔ひびの杭列・ベか舟を描いた帯。装飾扱い（`aria-hidden`）で、情報は全て本文にある | 外部画像不可。実際の展示物（ベか舟・海苔ひび）を題材にした図。写真が入るまでの仮の絵であり、実物とは異なる |
| 英語 | 画面最上部に常設の「English information」リンク、ページ末に`lang="en"`の英語セクション（概要2文、会期・時間・料金・会場・アクセス・イベント・予約・バリアフリー・連絡先）。ヒーローに英語名も併記 | 観光の英語話者が探さずに見つけられる位置と、日本語を読まずに判断できる情報量 |
| イベント | 日付を大きく、名称と時間を並べたカード。予約方法は別セクション（`#reserve`）に集約。電話はタップできるリンク | 家族連れ・高齢者が日付で選べる。電話予約を主な動線として大きく表示 |
| 操作 | ボタンは高さ約44px以上、フォーカス枠あり、本文へのスキップリンクあり | 高齢の来館者、キーボード・スマホ操作 |

## 参考にしたものと確認した範囲
- 参照したのは、フォルダ内の `anything-frontend-art-direction` スキルの本文（`SKILL.md`、`references/visual-direction.md`）に記された手順と、掲載されている事例の要約（青森県立美術館／CINRA、ZENBI、GOV.UK の重要情報を先に置く指針など）です。
- **事例の外部ページや画面図は開いていません（この環境でネットワークを使っていません）。** そのため、見本の実見は未完了で、事例の見た目を根拠にした判断はしていません。借りたのは「施設案内では開館時間・休館日など行き先の情報を大きな文字の近くに置く」という考え方だけです。
- 二案を並べる比較、実ブラウザでの表示確認、実描画の書体確認、狭幅・広幅のスクリーンショット確認は**行っていません**。コード上の指定（フォント指定、レスポンシブのCSS）に基づく設計です。

## 未確認・要確認
- `#reserve` はWeb予約フォームの仮のリンク先です。実フォームのURLが決まったら差し替えてください。
- 祝日と月曜が重なる日（5月初めの連休など）の休館日は、依頼の規定どおり「祝日の場合は翌平日」と記載するだけにしています。具体的な休館日の一覧は載せていません。
- 英語の概要は依頼文からの私の訳です。館の確認を取ってください。
