# DESIGN-NOTES

## 配色
- 地は和紙・干潟の泥を思わせる生成り（#f6f1e7）、見出し・帯は深い海の青緑（#14323f / #1f4a5c）、強調は錆色（#9a4318）。展示の主題（干潟・海・海苔）から取った。
- 本文 #1b2a30 on #f6f1e7 は十分なコントラスト（約13:1）。錆色は小さい見出しラベルのみ（約6:1）。色だけに頼らず、位置・太字でも区別。**比率は目測の概算で、ツールでは未計測。**

## 書体（FONTS.md の範囲内）
- 見出し・日付・導入文：Noto Serif CJK JP（資料館らしい落ち着き）。本文・表：Noto Sans CJK JP（小さい文字でも読みやすい）。英語部分は sans を指定。
- 本文は 18px 相当・行間1.85。高齢の来館者を想定。

## 構図・情報の順序
利用者の判断順（行くか → いつ → どう行くか）に並べた。
1. 展覧会名・会期（ヒーロー）。
2. 要点4枠（会期／開館時間／観覧料／アクセス）。スマホでも最初の画面付近で、行く・行かないの判断材料が揃う。
3. 概要 → 観覧案内 → 関連イベント＋予約（電話は大きなタップ可能ボタン）→ アクセス・バリアフリー。家族連れ・高齢者向けに「無料の対象」を明記。
4. English：ヘッダー右上に常時見える「English」リンク（ページ内アンカー）と、末尾に英語の完結した情報ブロック（概要・日時・料金・アクセス・予約）。
- 写真が無いため、ヒーロー下に自作のインラインSVG（干潟・ベか舟・海苔ひび）を置いた。写真の代用であり、実物の舟の形を忠実に描いたものではない。

## 技術面
- 単一HTML、外部読込みなし。1カラム基本、720px以上で複数列。タップ対象は44px以上を意識。キーボード用フォーカス表示、スキップリンク、`prefers-reduced-motion` 対応、`lang`属性（英語部分）。
- 予約の `#reserve` は同ページ内の予約欄。Web予約フォームは未用意のため「準備中」と明記（偽のフォームは置いていない）。

## 要確認・前提
- 会場名の英訳（Municipal Local History Museum）、地区名の英語表記は仮訳。
- 「祝日の場合は翌平日」の個別日（例：5月の連休）の扱いは依頼に無いため記載していない。
- 参考にした外部資料は無い。ブラウザでの実表示確認・実機確認は**行っていない**（コード上の確認のみ）。
