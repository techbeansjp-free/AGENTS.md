# 在庫の引当て 仕様説明（業務担当者向け）

## この仕様で変わること

注文を受けた時点で在庫を引き当てる（取り置く）。これまでは出荷の直前に引き当てていたため、受注後に在庫が足りないことが分かる場合があった。

## 規則

- 在庫が足りない注文は、引き当てずに「入荷待ち」にする。入荷待ちの注文は、入荷した順ではなく注文を受けた順に引き当てる。
- 引当ては、注文が確定した時点で行う。たとえば、顧客が注文画面で「確認へ進む」を押した時点で、在庫が取り置かれる。
- 取り置いた在庫は、注文が取り消されると戻る。
- 予約商品は、この規則の対象外とする。

## 画面の表示

注文の詳細画面に、引当ての状態（引当て済み・入荷待ち）を表示する。
