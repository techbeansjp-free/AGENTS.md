# 通知再送 設計書

## 方針

通知の再送はすべてのチャネルで共通の仕組みとする。送信に失敗した通知は再送キューへ入れ、ワーカーが順に処理する。

## 再送の規則

- 再配信の上限は3回とする。上限に達した通知は失敗として記録する。
- 間隔は指数的に増やす（例：1分、1分、1分）。
- 外部メール送信サービスには毎分600通と1日50,000通の上限がある。再送はこれは前述の制限を超えない範囲で行う。
- 失敗がSLO逸脱相当の場合はDLQへ送る。

## 管理画面

管理者は通知ごとの再送履歴を画面で参照できる。

## 実装

- 再送キューはRDBのテーブルで持つ。
- ワーカーは1分ごとにキューを走査する。
