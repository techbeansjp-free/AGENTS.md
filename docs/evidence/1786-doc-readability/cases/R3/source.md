# 元資料：通知の再送に関する要求（合成）

サービス責任者（2026-11-10、要求メモ）：

- メール通知の送信に失敗したら、自動で再送する。再送は最大3回まで。
- 再送の間隔は回数ごとに長くする（指数的に増やす）。1回目の待ち時間は1分。
- 利用者が通知を停止（配信停止）した場合、未送信の再送は行わない。
- 管理者は通知ごとの再送履歴を画面で参照できる。
- 今回の対象はメール通知だけ。push通知は今回扱わない。
- 外部メール送信サービスの送信上限は毎分600通。アカウント全体の1日の上限は50,000通。

用語（既存の運用文書による）：

- 再送：送信失敗後にシステムが自動で行う送信。
- 再配信：管理者が画面から手動で行う送信のやり直し。
