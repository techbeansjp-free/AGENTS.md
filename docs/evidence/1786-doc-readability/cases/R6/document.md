# 社内アプリのログインを新しいSSOへ移す

## 目的

依頼者（情報システム部長、2026-11-20）：「社内の全アプリのログインを新しいSSOへ移したい。」

得たい結果：社員が社内の主要アプリに、新しいSSOの1回のログインで入れる。

## 完了の基準

- 対象の12個のうち、SAML対応の10個に新しいSSOでログインできる。
- 移行中のログインの停止は、各アプリで1時間以内とする。

## してはいけないことと対象外

- 禁止：本番の認証設定を変更した後、セキュリティ担当の承認を得る（社内規程）。
- 対象外：SAMLに対応していないアプリ（起票者の判断）。

## 決まっていること

- 移行の順序は、利用者数の多いアプリからとする（情報システム部長、2026-11-21、議事録）。

## 背景と根拠

- 確認済み：対象のアプリは12個。
- 確認済み：経費精算と勤怠はSAMLに対応していない。

## 手段の案

要求ではない。アプリごとにSSOの設定を追加し、旧ログインと並行して動かす。

## 依存と未決

- 旧ログインは移行完了の翌日に停止する（決定済み）。
