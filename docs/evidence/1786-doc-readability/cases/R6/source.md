# 元資料：SSO移行の依頼（合成）

## 依頼者の原文

情報システム部長（2026-11-20、会議）：

> 社内の全アプリのログインを新しいSSOへ移したい。移行中も、現行のログインで入れなくなる時間を作らないで。

## 決定

- 移行の順序は、利用者数の少ないアプリからとする（情報システム部長、2026-11-21、議事録）。

## 規則

- 本番の認証設定の変更は、セキュリティ担当の承認を得てから行う（社内規程）。

## 観測

- 対象のアプリは12個。
- そのうち経費精算と勤怠の2個は、SSOが使うSAMLに対応しているかを未確認。

## 未決

- 移行の完了後に旧ログインを停止する日。判断者は情報システム部長。
