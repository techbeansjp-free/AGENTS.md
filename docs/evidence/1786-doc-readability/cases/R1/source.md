# 元資料：CI改善の依頼（合成）

## 依頼者の原文

プロダクト責任者（2026-11-02、チャット）：

> CIが遅くて、PRを出してから確認が終わるまでの待ち時間が長い。重複しているテストや重すぎるテストを整理して、PRの確認を10分以内で終わるようにしたい。

> テストを消すなら、それで何を守れなくなるかを必ず説明してほしい。

## 決定

- 必須checkの名前は変えない（リポジトリ管理者、2026-11-03、Issue #12のコメント）。

## 観測

- PRのCIの所要時間は平均18分（直近30回の成功run）。
- 最も遅いjobはe2eで、平均11分。
- e2eの実行条件（いつ・どのPRで流すか）の見直しについて、誰も決定していない。
