# 会員がパスワード再設定メールを受け取れずに問い合わせる件数を減らす

## 目的

依頼者（サポート責任者、2026-11-18、チャット）：「パスワード再設定のメールが届かないという問い合わせが毎週20件くらいある。減らしたい。」

得たい結果：会員が自分でパスワードを再設定でき、サポートへの問い合わせが減る。

## 完了の基準

- 再設定メールの送信失敗が、送信ログで会員ごとに確認できる。
- 再設定画面に「メールが届かない場合」の案内（迷惑メールフォルダーの確認、再送ボタン）が表示される。
- 再送ボタンは同じ会員につき10分に1回まで押せる。
- 効果の測定は本Issueの完了に含めない。リリース後4週間の問い合わせ件数は、サポート責任者が別に確認する。

## してはいけないことと対象外

- 禁止：再設定メールの本文に、パスワードそのものを書かない（セキュリティ規程）。
- 禁止：会員のメールアドレスを、サポート担当者以外の画面に表示しない（個人情報の取扱規程）。
- 対象外：SMSでの再設定。費用の判断が必要なため、別Issueで扱う（サポート責任者、2026-11-18）。

## 決まっていること

- 再送の間隔は10分（サポート責任者、2026-11-18、チャット）。

## 背景と根拠

- 確認済み：直近4週間の該当問い合わせは週平均21件（問い合わせ管理ツールの集計）。
- 推論：迷惑メールフォルダーへの振り分けが主な原因と考えられるが、未確認である。

## 手段の案

要求ではない。送信ログは既存のログ基盤へ出力する。案内文はサポート責任者に確認してもらう。

## 依存と未決

- 未決：案内文の最終的な文面。判断者はサポート責任者。文面が決まるまで、画面の実装は仮の文面で進めてよい。
