# 画像変換ライブラリ 技術調査報告

## 結論

libXを採用する。

## 根拠

- 性能：libXはlibYより約3倍速い（WebP、1,000枚の中央値で120ms対180ms）。
- サーバー環境でも同じ速度が出ることを確認した。
- libXのメモリ使用量はlibYの半分である。
- libXはAVIFの変換に対応しており、検証済みである。
- ライセンス：libXのライセンスはApache-2.0、libYはAGPL-3.0である。
- 保守：libYの最終リリースは2024年3月である。

## 補足

法務はlibYの採用も条件付きで認めた。libXに問題が出た場合はlibYへ切り替えられる。
