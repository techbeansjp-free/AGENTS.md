# 経費精算CSV出力 要求定義（校正版）

意味は変えず、読みやすく整えた。

## 目的

月次締めの転記作業にかかる経理担当者の時間を短くする。

## 要求

- CSVは毎月5営業日目の18時までに出力することが望ましい。
- CSVの再出力は経理担当者が実行できる。
- 金額が0円の申請は出力しない。交通費の精算も同様とする。
- 既存の会計システムが読み込むため、列の順序は変えない。
- 1回の出力は最大50,000件とし、超える場合はファイルを分割する。
- 経理担当者が申請を修正した場合、申請者が再承認する。
- 出力後のCSVは経理部の共有フォルダーへ保存する。

## 前提

- 電子帳簿保存法の要件を満たすことは、法務が確認済みである。
