# 元資料：承認済みの要求定義書 v1（合成）

この版は経理責任者が2026-10-20に承認した。以下の「校正版」は、担当者が「意味は変えず、読みやすく整えた」として提出したものである。

## 経費精算CSV出力 要求定義 v1

1. 目的：経理担当者が月次締めで行う転記作業の時間を減らす。
2. CSVは毎月5営業日目の18時までに出力されなければならない。
3. 承認前の申請をCSVに含めてはならない。
4. CSVの再出力は経理責任者だけが実行できる。
5. 金額が0円の申請は出力しない。ただし交通費の精算は0円でも出力する。
6. 既存の会計システムが読み込むため、列の順序と文字コード（Shift_JIS）は変えない。
7. 電子帳簿保存法の要件を満たすかは、法務に未確認である。
8. 1回の出力は最大5,000件とし、超える場合はファイルを分割する。
9. 申請者が申請を修正した場合、経理担当者が再承認する。
10. 出力したCSVは経理部の共有フォルダーに保存する。
