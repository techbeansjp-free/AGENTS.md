# 業務の画面（管理画面・ダッシュボード・入力画面）で調べる項目

人物の設定よりも、役割と作業を調べる。名前・年齢等の設定は作らない。

| 項目 | 例 | デザインへの効き方 |
| --- | --- | --- |
| 役割と権限 | 責任者、担当者、閲覧のみ | 操作の出し分け、操作できない理由の示し方 |
| 主な作業と頻度 | 数秒ごとの監視、月1回の編集 | 一覧の密度、操作の近さ、初期表示 |
| 急ぎ方と判断 | 数秒で異常に気付きたい | 異常の目立たせ方、並べ方、色以外の手掛かり |
| 誤ったときの損失 | 請求先の誤り、出荷の遅れ | 確認の段階、入力の検証、取り消しの手段 |
| 扱うデータ | 件数、桁、欠け・取得失敗 | 表の構成、空・失敗・読込み中の状態 |
| 使う環境 | 常時表示のPC、巡回中のタブレット | 幅ごとの構成、離れて見たときの読みやすさ |
| 既存の決まり | デザインシステム、既存画面の作法 | 部品と変数の再利用、新しい部品を作らない |

各項目は、根拠（依頼文・データ・既存の画面の出典）か仮説かを書く。業務の流れが分からない場合は、仮説と、確かめるべき相手（業務の責任者等）を書く。
