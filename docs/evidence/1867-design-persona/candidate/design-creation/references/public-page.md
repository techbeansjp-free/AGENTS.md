# 公開ページ（LP・案内・紹介）で調べる項目

| 項目 | 例 | デザインへの効き方 |
| --- | --- | --- |
| 誰が見に来るか | 近隣の家族連れ、高齢者、観光客 | 言葉の難しさ、文字の大きさ、言語の切り替えの位置 |
| 何を決めに来るか | 行くか・いつ・どう行くか、申し込むか | 最初の画面に置く情報、情報の順序 |
| 決めるのに要る情報 | 会期・料金・アクセス、価格・実績 | 見出しの立て方、要約の置き場所 |
| ためらう理由 | 子連れで入れるか、費用、信頼できるか | 不安に答える情報の位置、信頼の材料 |
| 見る環境 | スマートフォン中心、移動中、通信が遅い | 狭い幅の構成、重い要素を避ける |
| 求める行動 | 予約、問合せ、資料請求 | 行動の入口の位置と数 |
| 伝えたい印象 | 落ち着いた、親しみやすい、専門的 | 配色、書体、余白、写真の代わりのもの |

各項目は、根拠（依頼文・資料・公開情報の出典）か仮説かを書く。調べても分からない項目は仮説とし、外れたときに変わる判断を書く。
