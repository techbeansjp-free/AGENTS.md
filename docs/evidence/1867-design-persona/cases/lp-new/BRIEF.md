# 依頼：出張のスマートフォン相談サービスのLP

湊川市（架空）で個人事業主が1人で始める、出張のスマートフォン相談サービス「ひだまりスマホ相談」（架空）のLPを1枚作りたい。ページを見た人に、申し込みか問合せをしてもらえるようにしたい。

## 利用者

- スマートフォンの使い方に困っている人と、その家族。
- 開業の準備中に受けた問合せの記録を `inquiries.md`（このフォルダ）に置いた。

## サービスの内容（このページに必ず載せる）

- サービス名：ひだまりスマホ相談
- 一言：ご自宅に伺って、スマートフォンの「困った」を一緒に解決します。
- できること：電話・LINEの設定、写真の送り方、文字の大きさの調整、詐欺のメール・SMSの見分け方、キャッシュレス決済の初期設定、マイナンバーカードの読み取りの手伝い（申請の代行はしない）
- 料金（税込）：初回 60分 3,300円。2回目以降 60分 4,400円。延長は30分ごとに2,200円。
- 出張費：湊川市内は無料。北浜市・西岡町は550円。
- 支払い：現金、または銀行振込（訪問の後）
- 対応地域：湊川市、北浜市、西岡町
- 受付：電話 0120-000-482（平日 9:00〜18:00）、またはWebの申込みフォーム（`#apply`へのリンクでよい）
- 担当：代表 1名（家電量販店のスマートフォン売場で8年勤務）。訪問時は名札と身分証を見せる。
- 家族の同席、家族からの申込みもできる。家族が遠方に住む場合は、希望すれば訪問の後に家族へ内容を報告する（無料）。
- キャンセル：前日までは無料。当日は1,100円。
- よくある質問（3件以上）：機種（iPhone・Android）を問わない／機種変更の手続きの代行や端末の販売はしない／暗証番号やパスワードは聞かず、本人に入力してもらう

## 制約

- 単一のHTMLファイル（CSS・JavaScriptはファイル内に書く）。外部のURLから画像・書体・スクリプトを読み込まない。写真はまだ無いので、写真の代わりに使うものは自分で決めてよい（外部画像は使えない）。
- 使える書体は `FONTS.md`（このフォルダ） を参照。

- `out/index.html`：上のページ。
- `out/DESIGN-NOTES.md`：主要な設計判断（配色・書体・構図・情報の順序など）と、それぞれをこの依頼のどの内容・利用者に対応させて選んだかを、短く書く。参考にしたものがあれば出典と、確認した範囲を書く。
