# 4. 機能設計

機能設計ドキュメントは、機能別に以下のディレクトリに分割されています。

## ドキュメント一覧

機能設計ドキュメントは、機能別にディレクトリを分割して管理します。

各機能ディレクトリには `README.md` を配置し、その機能に関するすべての情報（機能フロー、シーケンス図、API仕様など）を含めます。

**テンプレート**: [`機能名/`](./機能名/) ディレクトリをコピーして、`{機能名}/` として使用してください。

**使用例**:

1. `機能名/` ディレクトリをコピー
2. `ログイン/` として保存
3. `ログイン/README.md` 内の `{機能名}` を `ログイン` に置き換え
4. 機能フロー、シーケンス図、API仕様を実際の内容に置き換え

**機能ディレクトリの例**:

- `ログイン/README.md` - ログイン機能の詳細設計
- `ユーザー登録/README.md` - ユーザー登録機能の詳細設計
- `注文処理/README.md` - 注文処理機能の詳細設計
- `共通機能/README.md` - 共通機能の詳細設計
