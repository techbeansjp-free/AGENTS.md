# 2. ステークホルダー

## 2.1. 役割一覧

| 役割                     | 説明           | 関心                                                    |
| ------------------------ | -------------- | ------------------------------------------------------- |
| 開発者                   | 実装・保守担当 | アーキテクチャ、ディレクトリ構成、API・データ・画面仕様 |
| プロジェクトマネージャー | 進捗・品質管理 | プロジェクト概要、スコープ、成果物                      |
| クライアント / 発注者    | 要件・受入判断 | 機能・画面・非機能要件の理解                            |

## 2.2. ドキュメントの読み方（役割別）

- **開発者**: 03 アーキテクチャ、04 ディレクトリ構成、02 画面設計、03 データ設計、04 機能設計、05 エラー処理と外部通知を中心に参照

- **クライアント**: 01 プロジェクト概要、03 アーキテクチャ（構成図）、02 画面設計、04 機能設計の API 一覧を参照
