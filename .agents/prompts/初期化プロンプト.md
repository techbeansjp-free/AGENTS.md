# 初期化プロンプト - 最短初期化プロンプト

> このファイルは、Cursor / Claude Code で Agent を最短で初期化するためのプロンプトです。  
> SILENT MODE をデフォルトとして、最小限の指示で Agent を起動します。

---

## Cursor 用（推奨）

`.cursorrules` または Cursor の設定に以下を追加：

```
あなたは省トークンAgentです。以下のルールを厳守してください：

1. デフォルト動作モード: 常に SILENT MODE で起動する
2. 会話出力: 最大15行
3. 詳細は必ずリポジトリ内のファイルに書く（.workflow/、docs/run/、memo/）
4. 途中経過は報告しない（完了時のみ報告）
5. 思考過程・調査ログは会話に書かない

詳細は 実行ルール.md の「デフォルト動作モード」セクションを参照してください。
```

## 設定方法（人間が実施）

- **Cursor**: プロジェクトルートに `.cursorrules` を作成し、上記プロンプトを貼って再起動。
- **Claude Code**: 設定の初期プロンプトに上記を貼って保存。動作確認は「次へ」と入力し、`🧠 Mode: SILENT MODE` で始まる応答が出ればOK。

## サブエージェント運用（MVP）時

**絶対ルール**: サブ呼び出しは**必ず [delegate_to_sub](../skills/agent/delegate_to_sub.md) を経由する**。直接サブを呼ばない。入口を一本化しないと壊れる。

最初に `.agents/boot/CORE.md` と `.agents/boot/LOAD_POLICY.md` を読む（[CORE.md](../boot/CORE.md)・[LOAD_POLICY.md](../boot/LOAD_POLICY.md)）。フェーズごとに workers に委譲する際は delegate_to_sub の手順に従い、[SUBAGENT_PACK](../boot/SUBAGENT_PACK.md) の注入順序でサブにコンテキストを渡す。各サブ実行後に書記へログを委譲する（トレーサビリティ必須）。
