# Issue実行テンプレート - Issue 実行テンプレート

> このファイルは、SILENT MODE 前提の Issue 実行テンプレートです。  
> 1行指示で Agent を起動し、自律的に連続作業を進めます。

---

## 重要：返答フォーマットのルール

**SILENT MODE 時は、返答の先頭に必ず `🧠 Mode: SILENT MODE` を付与する**。

これにより：
- 「全文が出ないのは仕様」が即わかる
- 「全文出てない＝失敗？」の誤解を防げる
- 結果的に省トークンになる

---

## 基本パターン（1行指示）

### パターン1：次のフェーズに進む

```
次へ
```

**期待される動作**:
- 現在のフェーズを完了
- 次のフェーズに自動進行
- SILENT MODE で最小限の報告のみ

**期待される返答フォーマット**:
```
🧠 Mode: SILENT MODE
✅ 完了フェーズ: {現在のフェーズ名}
📄 更新対象:
  - .workflow/{issue}/{現在のフェーズ名}.md
🔜 次フェーズ: {次のフェーズ名}
⚠️ 判断が必要: なし
```

### パターン2：特定のフェーズを実行

```
02_設計を実行
```

**期待される動作**:
- `02_設計.md` を作成・更新
- SILENT MODE で最小限の報告のみ

**期待される返答フォーマット**:
```
🧠 Mode: SILENT MODE
✅ 完了フェーズ: 02_設計
📄 更新対象:
  - .workflow/{issue}/02_設計.md
🔜 次フェーズ: 03_実装計画
⚠️ 判断が必要: なし
```

### パターン3：連続フェーズ進行

```
01_要件定義から03_実装計画まで進めて
```

**期待される動作**:
- 01 → 02 → 03 を連続実行
- 各フェーズ完了時に最小限の報告
- SILENT MODE を維持

### パターン4：タスク実行

```
TASK-20260209-001 を実行
```

**期待される動作**:
- `03_実装計画.md` から該当タスクを特定
- タスクを実行
- SILENT MODE で最小限の報告のみ

## 詳細要求パターン（通常モードに昇格）

### パターン5：全文を確認したい

```
02_設計の全文を見せて
```

**期待される動作**:
- 通常モードに切り替え
- `02_設計.md` の全文を出力

### パターン6：詳細を説明してほしい

```
01_要件定義の詳細を説明して
```

**期待される動作**:
- 通常モードに切り替え
- 要件定義の詳細を説明

### パターン7：理由を教えてほしい

```
なぜこの設計にしたか理由を教えて
```

**期待される動作**:
- 通常モードに切り替え
- 設計判断の理由を説明

---

## レビューパターン

### パターン8：レビュー実行

```
レビューして
```

**期待される動作**:
- レビューを徹底的に実施
- 会話には指摘件数とサマリのみ
- 詳細は `04_review.md` に記載

### パターン9：レビュー詳細を確認

```
レビュー詳細を見せて
```

**期待される動作**:
- `04_review.md` の内容を出力
- 通常モードで詳細を表示

---

## Issue 全体の実行パターン

### パターン10：Issue を最初から最後まで実行

```
この issue を最初から最後まで実行
```

**期待される動作**:
- 00_要求定義 → 01_要件定義 → 02_設計 → 03_実装計画 → 実装 → 04_review
- 各フェーズ完了時に最小限の報告
- SILENT MODE を維持

### パターン11：Issue を特定フェーズまで実行

```
この issue を03_実装計画まで実行
```

**期待される動作**:
- 00 → 01 → 02 → 03 を連続実行
- 各フェーズ完了時に最小限の報告
- SILENT MODE を維持

---

## エラー対応パターン

### パターン12：エラーが発生した場合

```
エラーが発生しました。原因を説明して
```

**期待される動作**:
- 通常モードに自動切り替え
- エラーの原因を詳細に説明
- 修正案を提示

---

## 運用チェックリスト（AI・人間共通）

- **開始時**: Issue ディレクトリ・`00_要求定義.md` の存在と次フェーズを確認。
- **実行時**: 出力先頭に `🧠 Mode: SILENT MODE`、会話15行以内、詳細はファイルに記載。
- **完了時**: 次フェーズ・判断項目・`.workflow/` 更新を確認。
