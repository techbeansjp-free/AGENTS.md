# capability: extract-goals

**目的**: 要求・依頼から目的・ゴールを抽出し、00_要求定義の「目的」「成功基準」のたたき台を作る。

---

## 手順

1. 入力（00_要求定義のたたき台・ユーザー依頼文・親の目的）を読む。
2. 「何を達成するか」「どうなれば成功か」を 1 文〜数文で抽出する。
3. 受け入れ基準の候補を箇条書きで列挙する（検証可能な形で）。
4. 出力を 00_要求定義の「目的」「受け入れ基準」セクションに反映できる形式でまとめる。

---

## 制約・禁止

- 目的は 1 issue あたり 1 〜 3 個に絞る。曖昧な表現（「なんとなく」「できるだけ」）は具体化する。
- 受け入れ基準は「確認方法」が分かるように書く。参照元（親 00/01、REBUILD_PLAN 等）を必ず明記する。

---

## 成果物の形式

- **OUT**: 目的の短文一覧。受け入れ基準の候補リスト。00_要求定義にそのまま貼れる形。
- 次の capability（identify-assumptions）へ渡すときは、目的・基準候補をテキストで引き継ぐ。

---
