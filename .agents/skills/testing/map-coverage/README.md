# capability: map-coverage

**目的**: 受け入れ基準・BDD と実装・テストの対応を確認し、欠落を検出する。

---

## 手順

1. 入力（01 の受け入れ基準・BDD。実装・テスト成果物。generate-scenarios の出力）を読む。
2. 各受け入れ基準について「どの実装・どのテストでカバーしているか」を 1 行で書く。
3. カバーされていない基準があれば一覧にし、04_review の「未達・要対応」に記載する。
4. 必須成果物の欠落（00/01/02/03/04 の必須セクション不足）があれば検出し、指摘する。
5. カバレッジ対応表または不足一覧を 04_review に反映する。

---

## 制約・禁止

- 「通過」「未達」は検証方法とセットで書く。主観だけにしない。
- PHASES の DoD を満たしているかも本 capability で確認する。

---

## 成果物の形式

- **OUT**: カバレッジ対応表（基準 | 検証方法 | 結果）。未達・要確認の一覧。04_review に貼れる形。
- 必須成果物欠落の有無を 04_review の「レビュー結果」に含める。
