# spec ディレクトリ

このディレクトリは、ソフトウェア開発における **設計思想・設計原則・運用ルール** を定義する。

ここに記載する内容は **特定プロジェクトの仕様ではない。**

対象は以下である。

- 設計思想
- ディレクトリ構造方針
- 命名規則
- 仕様更新ルール
- 契約変更ルール
- AI開発運用ルール

本ディレクトリの内容は **言語・フレームワーク・プロジェクトに依存しない共通ルール**として利用する。

---

## spec の位置づけ

本プロジェクトでは仕様を次のように分離する。

|ディレクトリ|役割|
|---|---|
|spec|設計原則・運用ルール|
|docs|具体的なシステム仕様|
|backend / frontend|実装|
|tests|検証|

つまり

- **spec** = 設計憲法
- **docs** = 現在の仕様

---

## spec の特徴

spec は以下の特徴を持つ。

- 言語非依存
- フレームワーク非依存
- プロジェクト非依存
- 長期的に安定する
- 変更頻度が低い

そのため、複数プロジェクトで共通利用できる。

---

## Living Documentation

本プロジェクトでは仕様を **Living Documentation** として扱う。

仕様は開発とともに更新される。

基本ルール

- 実装変更 → docs 更新
- 仕様変更 → 実装更新

spec はその更新の基準となる。
