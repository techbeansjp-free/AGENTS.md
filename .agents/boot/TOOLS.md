# TOOLS - 使えるツール（要約）

> **AI 向け**: 使えるツールの一覧・I/O の形。手順・長文はここに書かず、必要時は各ツールの公式ドキュメントを参照する。

---

- **Read**: ファイル・ディレクトリの読み取り。パスを指定して内容を取得する。
- **Write / 編集**: ファイルの作成・更新。編集前に内容確認を推奨。書記以外は [capabilities/POLICY.md](../capabilities/POLICY.md) の範囲内のみ書き可。
- **Grep / 検索**: パターン・パス指定でコードベースを検索する。
- **実行**: コマンド実行は「手順とコマンド例の提案」まで。実際の実行結果の確認は人間または CI の責任範囲。

詳細は実行環境（Cursor / Claude Code 等）のツール仕様に従う。
