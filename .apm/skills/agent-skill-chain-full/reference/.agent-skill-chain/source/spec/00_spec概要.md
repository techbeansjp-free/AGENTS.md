# spec概要

このディレクトリは、ソフトウェア開発における設計思想および運用ルールを定義する。

ここに記載される内容は **具体仕様ではなく設計原則である。**

**参照タイミング**: 要求・設計 command（requirement-discovery、design-feature）の**実行前に**、LOAD_POLICY に従い本 spec 一式（00〜06・ai）を参照すること。

---

## 目的

spec は以下を目的とする。

- 設計判断の基準を統一する
- 可読性の高い構造を維持する
- 保守性を向上させる
- AIを活用した開発を容易にする

---

## spec と docs の違い

| 項目     | spec           | docs             |
| -------- | -------------- | ---------------- |
| 役割     | 設計原則       | 具体仕様         |
| 変更頻度 | 低い           | 高い             |
| 対象     | 全プロジェクト | 個別プロジェクト |

---

## spec の構成

spec は以下の要素で構成される。

- 設計原則
- ディレクトリ構造方針
- 命名規則
- 仕様更新ルール
- 契約変更ルール
- 設計判断の優先順位
- AI開発ルール
